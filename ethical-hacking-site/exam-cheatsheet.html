Information security basics

ComponentMeaningExam phrasing
ConfidentialityOnly authorised parties can read the dataEncryption, access control, sniffing attacks
IntegrityData is not altered without authorisationHashing, digital signatures, MITM tampering
AvailabilitySystems and data are accessible when neededDoS/DDoS, backups, redundancy
AuthenticityProof of identity of a user or systemPasswords, certificates, biometrics
Non-repudiationA party cannot deny having performed an actionDigital signatures, audit logs, timestamps
AccountabilityActions are traceable to an identityLogging, monitoring, unique user IDs

Penetration testing — frameworks and steps

PTES phases: pre-engagement → intelligence gathering → threat modelling → vulnerability analysis → exploitation → post-exploitation → reporting OSSTMM: operational security methodology — scope, channels (human/physical/wireless/communications), indicators of trust, controls, process/visibility, ten commandments of hygiene. NIST SP 800-115: planning → discovery → attack → reporting (with remediation). OWASP: risk-focused web testing — information gathering, configuration, authentication, session management, input validation, error handling, business logic, etc.

Types: black-box (zero knowledge), white-box (full knowledge), grey-box (partial); external vs internal; automated vs manual; covert vs overt.

Common trap. "Elements of information security" (CIA + authenticity, non-repudiation, accountability) is not the same as "six security challenges" (complexity, connectivity, third parties, insider threat, evolving threats, compliance). Read the exact wording.

Reconnaissance toolkit

Passive: Google dorks, WHOIS, DNS records, public records, social media, job ads Active: nmap (ports/services/OS), ping, traceroute, netcat, banner grabbing, vulnerability scanners (Nessus, OpenVAS), enumeration (users, shares, SNMP)

Incident response — six steps

1. Preparation 2. Identification 3. Containment 4. Eradication 5. Recovery 6. Lessons learned

Exam-writing rules

  • For "compare/differentiate", write a two-column table with at least four rows and end with a one-line conclusion.
  • For "explain the process/steps", number every step and state what happens at each stage.
  • For attack questions, always add a countermeasure paragraph — examiners award marks for defence.
  • For "with figure/illustrate", draw a labelled ASCII block diagram; an unlabelled arrow diagram loses marks.
  • Define the term first, even in a 3-marker, then explain the mechanism, then give one example.
