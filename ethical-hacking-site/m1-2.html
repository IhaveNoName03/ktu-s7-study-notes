The Hacker Landscape

Not all hackers are criminals. This page catalogues the many "hats," their motivations, and the kill-chain phases every intrusion follows — the skeleton the later modules hang on.

02

The Hacking Kill Chain

Phases

1Reconnaissance

Passive + active info gathering (footprinting, scanning) — map the target. See M2.

2Scanning & Enumeration

Find live hosts, open ports, services, users. See M2.

3Gaining access

Exploit a vulnerability to get in (SQLi, buffer overflow, phishing). See M3/M4.

4Maintaining access

Backdoors, rootkits, escalation — keep the door open. See M5.

5Covering tracks

Clear logs, hide files, wipe evidence. See M5.

+Skills of a hacker

Curiosity, scripting, networking, OS internals, patience, methodical note-taking.

What happens at each phase (worked view)

  1. Reconnaissance — attacker builds an attack-surface map: domains, IPs, staff, tech stack (no packets touch the target in passive recon).
  2. Scanning & Enumeration — Nmap finds 10.0.0.5:443 open; banner grab shows outdated web server; SMTP VRFY lists valid usernames.
  3. Gaining access — attacker exploits the outdated server (or sends a phishing link) and lands a shell as a low-priv user.
  4. Maintaining access — drops a scheduled-task backdoor and escalates to admin so re-entry survives a reboot.
  5. Covering tracks — clears the Security event log and timestomps dropped files before leaving.
Mnemonic for the phases: Recon → Scan → Gain → Maintain → Cover (RSGMC). Every later module is one of these phases in detail.
03

Reconnaissance in Practice

Phase 1, detailed

Before any exploit, an attacker maps the target. Two styles:

Passive (low risk of detection)

  • OSINT — WHOIS, DNS records, certificate transparency logs
  • Social media, job postings (tech stack leaks), LinkedIn
  • Search-engine dorking, archived sites (Wayback)
  • Shodan / passive DNS for exposed assets

Active (touches the target)

  • Port scanning, OS & service fingerprinting
  • Banner grabbing, traceroute
  • More detectable — may trip IDS/IPS
The goal is an attack surface map: live hosts, open ports, versions, users, and the easiest entry (often a person, not a port).
04

Gaining & Keeping a Foothold

Phases 3–5

Initial access

Phishing link, a public exploit (e.g. unpatched web app), or stolen creds. The weakest link decides.

Privilege & persistence

Escalate to admin/root, then plant a backdoor / scheduled task so re-entry survives a reboot.
