Q1

Classification vs regression scenario

3 marks

Explain a scenario in which classification is better than regression.

Answer

Definitions. Regression predicts a continuous target y ∈ ℝ (a quantity with a meaningful order and distance, e.g. price, temperature, height). Classification predicts a categorical label y ∈ {c₁,…,cₖ} (a discrete class with no inherent numeric distance between labels).

Scenario where classification wins: spam detection. Given an email's word frequencies, decide spam vs ham. There is no meaningful continuous quantity being measured — "spamness" is not a number on a ruler. If we forced a regression model to output a real number (say 0.73), we would still have to impose an arbitrary cut-off (e.g. ≥ 0.5 ⇒ spam) to get a decision, and the difference between 0.2 and 0.7 would carry no physical interpretation. A classifier instead models P(spam | email) directly and returns the label, which is exactly what the application needs.

Why classification is the better tool here:

  • The target is discrete and unordered; the evaluation metric is accuracy / precision / recall, not squared error.
  • Classifiers calibrate a probability and apply a principled decision threshold; the probability is interpretable as confidence.
  • Class-conditional likelihoods P(words | class) are natural to estimate (e.g. Naive Bayes), whereas forcing a Gaussian noise model on a label is unnatural.

Other examples: diagnosing disease (yes/no), predicting exam pass/fail, recognising a handwritten digit, sentiment (positive/negative/neutral).

Contrast: use regression instead when the output is genuinely continuous — house price, stock price, temperature, number of minutes a user will stay.

Exam tip: The key phrase is "no natural ordering or distance between outputs." State that first, give one concrete scenario, then explain why a regression number would need an arbitrary threshold. (3 marks: definition + scenario + justification.)

Q2

Choosing the learning method

3 marks

Identify the suitable learning method: a) Predict stock prices b) Detect an email as spam.

Answer

Both tasks are supervised because labelled examples (input X and known output y) are available during training. They differ only in the type of output, which decides regression vs classification.

  • (a) Predict stock prices — supervised regression. Historical prices plus features (volume, indices, news sentiment) form labelled pairs (X, price) with a continuous target. Fit a function f(X) → ℝ using linear/multiple regression, polynomial regression, SVR, random-forest regression or a neural network. Evaluate with MSE / RMSE / MAE / R². Note that financial series are noisy and non-stationary, so a simple model is often preferable and time-based validation is essential.
  • (b) Detect spam — supervised classification. A labelled corpus of emails (spam / ham) is available; each email is represented by a bag-of-words or TF-IDF vector. Learn P(class | features) with Naive Bayes, logistic regression or an SVM, and output a discrete label. Evaluate with accuracy, precision / recall / F1, ROC-AUC; care about false positives (legitimate mail sent to spam).

Decision rule: ask (i) are labels available? → supervised; (ii) is the target continuous? → regression, categorical? → classification. If no labels were available and we only wanted to group similar emails, that would be unsupervised clustering instead.

Exam tip: For each part name the paradigm (supervised), the task (regression or classification), a suitable algorithm and a suitable metric. That four-part structure reliably earns full marks.

Q3

General MLE method

3 marks

Explain the general MLE method for estimating the parameters of a probability distribution.

Answer

Principle. Maximum Likelihood Estimation chooses the parameter value θ̂ that makes the observed data most probable — i.e. it maximises the likelihood of the sample actually seen.

Given i.i.d. observations x₁,…,xₙ ~ p(x | θ): L(θ) = ∏_{i=1..n} p(xᵢ | θ) (likelihood: product of densities/pmf) ℓ(θ) = log L(θ) = Σ_{i=1..n} log p(xᵢ | θ) (log-likelihood) Solve dℓ/dθ = 0 for θ̂ ; verify d²ℓ/dθ² < 0 (maximum).

Why the log? A product of many small densities underflows numerically; the log turns the product into a sum. Since log is monotonic, the θ maximising ℓ also maximises L. For an i.i.d. sample the log-likelihood is a sum of n terms, so derivatives are straightforward.

General procedure (write these steps in the exam):

  1. Write the pmf / pdf p(x | θ) for a single observation.
  2. Form the likelihood L(θ) = ∏ p(xᵢ | θ) over all observations.
  3. Take logs to get ℓ(θ), dropping constants.
  4. Differentiate w.r.t. θ, set to zero (the score equation) and solve for θ̂.
  5. Check the second derivative is negative to confirm a maximum.

Properties. MLE is consistent (θ̂ → true θ as n → ∞), asymptotically normal and asymptotically efficient (attains the Cramér–Rao lower bound) under regularity conditions. For finite samples it can be biased (e.g. the MLE of variance divides by n, not n−1) and can overfit with small data.

MAP connection. Adding a prior P(θ) and maximising P(θ | D) ∝ P(D | θ)P(θ) gives MAP estimation; MLE is the special case of a uniform prior. Gaussian prior ⇒ L2 regularisation, Laplace prior ⇒ L1.

Quick example. For Bernoulli(p) with data H,H,H,T: L = p³(1−p), ℓ = 3 ln p + ln(1−p), 3/p − 1/(1−p) = 0 ⇒ p̂ = 3/4 — the sample proportion, as intuition suggests.

Exam tip: Always show the likelihood, the log-likelihood, the derivative set to zero, and the second-derivative check. Marks are awarded for each step, not just the final answer.

Q4

Linear vs logistic regression

3 marks

Compare linear regression and logistic regression models.

Answer

Both learn a linear score z = w·x + b, but they use it for different tasks and fit it with different objectives.

AspectLinear regressionLogistic regression
TaskRegression (continuous target)Classification (categorical target)
Predictionŷ = w·x + bP(y=1|x) = 1/(1+e−(w·x+b)) = σ(w·x+b)
Output rangeAny real number (−∞, ∞)Restricted to (0, 1)
Link functionIdentityLogit (sigmoid inverse): log(p/(1−p)) = w·x + b
Loss / fittingLeast squares: minimise Σ(yᵢ−ŷᵢ)² (closed-form normal equations XᵀXβ = Xᵀy)Maximum likelihood: minimise cross-entropy −Σ[y ln p + (1−y) ln(1−p)] (iterative, e.g. gradient descent)
Decision boundaryNot applicableLinear hyperplane w·x + b = 0 (at threshold 0.5)
MetricsMSE, RMSE, MAE, R²Accuracy, precision/recall, log-loss, ROC-AUC
ExampleHouse price from area, bedroomsSpam / ham from word counts

Why the sigmoid? It maps the unbounded score z into a probability in (0,1), and the logit transform log(p/(1−p)) makes the log-odds linear in x — which is why the model is called logistic regression.

Common ground: both are parametric, discriminative, linear-in-the-parameters models; both can be extended with polynomial / interaction features or regularisation (ridge / lasso).

Key trap: despite the word "regression" in its name, logistic regression is a classification algorithm because its output is a class probability.

Exam tip: A well-labelled comparison table earns most marks; add the sigmoid formula and the log-odds interpretation to show understanding, and finish with the naming trap.

Q5

Feed-forward net with lateral inhibition

3 marks

Construct a feed-forward network with four input nodes, three hidden nodes and three output nodes with lateral inhibition in the output layer.

Answer

Architecture. Three layers: 4 input units → 3 hidden units → 3 output units. Information flows one way (feed-forward, no cycles). Every input connects to every hidden unit; every hidden unit connects to every output unit. In addition, the output units send inhibitory links to each other (oᵢ ⊣ oⱼ for i ≠ j).

  x1 ─┐                    ┌─► o1 ←─────────┐
  x2 ─┼─► [ 4 inputs ] ──► h1 ─► o2 ←─┐  ⊣   │  inhibitory links
  x3 ─┤                 ┌─► h2 ─► o3 ←─┴─────┘  (o_i suppresses o_j, i≠j)
  x4 ─┘                 └─► h3
                 (all-to-all, feed-forward)

  x_i ──(w_ij)──► h_j ──(v_jk)──► o_k
  o_1 ⊣ o_2 ,  o_1 ⊣ o_3 ,  o_2 ⊣ o_3   (lateral, same layer)

Computation. hⱼ = f(Σᵢ w_{ij} xᵢ + bⱼ); net output oₖ = g(Σⱼ v_{jk} hⱼ + cₖ − Σ_{m≠k} γ_{mk} oₘ), where γ ≥ 0 is an inhibition weight: the activation of a rival output subtracts from oₖ.

What lateral inhibition achieves. It implements competition: the most strongly activated output suppresses its neighbours, so the network converges toward a winner-take-all representation in which one output dominates and the others are driven toward zero. This:

  • sharpens contrast between competing patterns (like the visual system's edge enhancement / Mach bands),
  • makes the output sparse and easier to read as a single decision,
  • is the basis of competitive learning and self-organising maps.

Exam tip: Draw the three layers and label the inhibitory links among the outputs explicitly — the diagram is the main deliverable. Then give one sentence on winner-take-all and one on where it is used.

Q6

Optimal separating hyperplane

3 marks

What is the significance of the optimal separating hyperplane in SVM?

Answer

For linearly separable data there are infinitely many hyperplanes w·x + b = 0 that separate the classes. The optimal separating hyperplane (OSH) is the one that maximises the margin — the distance between the hyperplane and the nearest data points of each class.

Hyperplane: w·x + b = 0 Geometric margin (half-width) = 1 / ‖w‖ , total margin = 2 / ‖w‖ Constraints: yᵢ(w·xᵢ + b) ≥ 1 for all i OSH: minimise ½‖w‖² subject to those constraints → w = Σ αᵢ yᵢ xᵢ (only support vectors have αᵢ > 0)

Significance — why the maximum-margin solution is special:

  • Uniqueness: among all separators, the maximum-margin one is unique and well-defined by the optimisation.
  • Determined by support vectors only: the boundary depends solely on the few points lying on the margin; moving or removing other points leaves it unchanged. This makes the model sparse and memory-efficient.
  • Better generalisation: a large margin corresponds to low capacity / low VC dimension. By structural risk minimisation it reduces the expected test error — a small-margin separator is more likely to misclassify a new point near the boundary.
  • Robustness: the classifier is insensitive to noise and small perturbations of non-support points; it also admits a soft-margin extension (slack ξᵢ, penalty C) for noisy / overlapping classes.

Diagram idea: two clouds of points with a central solid line (the OSH) and two dashed lines through the support vectors; the gap between the dashed lines is 2/‖w‖ and should be as wide as possible.

Exam tip: Lead with "maximises the margin 2/‖w‖," then give at least three bullets (uniqueness, support-vector sparsity, generalisation / SRM, robustness). Mentioning soft margin is a bonus.

Q7

K-means parameters

3 marks

For K-means: which parameters are usually specified by the user, and what does the algorithm estimate?

Answer

User-specified (hyperparameters):

  • K — the number of clusters (the main choice, often selected by the elbow method or silhouette score);
  • initial centres — either explicit seeds or an initialisation scheme such as k-means++ (better spread, fewer poor local optima);
  • distance metric — Euclidean by default (Manhattan / cosine for other data);
  • convergence tolerance ε and maximum iterations — stopping criteria.

Estimated by the algorithm (learned parameters):

  • the cluster assignment c(i) ∈ {1,…,K} of every data point, and
  • the final centres / centroids μₖ (the mean of the points assigned to cluster k).
Repeat until centres stop moving: Assignment step: c(i) = argmin_k ‖xᵢ − μₖ‖² Update step: μₖ = (1/|Cₖ|) Σ_{i∈Cₖ} xᵢ Minimises the within-cluster sum of squares (inertia) Σₖ Σ_{i∈Cₖ} ‖xᵢ − μₖ‖².

Why this split matters: K-means is unsupervised — it receives only the feature matrix X, no labels. K must be supplied because it is not learned from the data; the algorithm only optimises assignments and centres for that fixed K. Bad initialisation can trap it in a local minimum, which is why multiple random restarts are common.

Exam tip: Make a two-column list (specified vs estimated). Naming k-means++, the objective (inertia), and the assignment/update alternation shows full understanding.

Q8

EM: supervised or unsupervised?

3 marks

Is EM a supervised or unsupervised learning method? Explain.

Answer

EM (Expectation–Maximisation) is an unsupervised method. It is applied to unlabelled data containing latent (hidden) variables — for example, in a Gaussian mixture model the hidden variable zᵢ indicates which component generated observation xᵢ, and that component label is never observed in the training set.

Data X observed; hidden Z unobserved; parameters θ. E-step: compute responsibilities γ(zᵢk) = P(zᵢ=k | xᵢ, θ^old) M-step: update θ to maximise Q(θ, θ^old) = Σᵢ Σₖ γ(zᵢk) log P(xᵢ, zᵢ=k | θ) Repeat — the observed-data log-likelihood P(X | θ) increases monotonically.

Why it is unsupervised:

  • No target labels y are used anywhere; the algorithm infers everything from the feature vectors alone.
  • The E-step infers the missing latent labels from the current parameters (soft assignment, not the hard assignment of K-means).
  • The M-step re-estimates the parameters (means, covariances, mixing weights) from those inferred responsibilities.

Example. Given a histogram of heights with two bumps, EM fits a two-Gaussian mixture: it first guesses which bump each person belongs to (responsibilities), then refits each Gaussian's mean/variance, iterating to convergence. This is density estimation / clustering — classic unsupervised tasks.

Nuance. EM can be adapted to semi-supervised learning when some labels are known (their responsibilities are fixed to 0/1), but in its standard form on unlabelled data it is unsupervised. It can also be used to fit missing-data problems and HMMs (Baum–Welch is a special case).

Exam tip: State "unsupervised," name the latent variables, describe E-step and M-step in one line each, and give the Gaussian-mixture example. Mention the monotonic likelihood increase for full marks.

Q9

Ensemble learning and non-linear data

3 marks

What is ensemble learning? Can ensemble learning using linear classifiers learn classification of linearly non-separable sets?

Answer

Ensemble learning trains several base models (weak learners) and combines their predictions — by majority vote for classification or averaging for regression — to obtain a predictor that is more accurate and more robust than any single member. The intuition is the "wisdom of crowds": errors made by diverse models tend to cancel.

  • Bagging (bootstrap aggregating): train base models on different bootstrap samples, reduce variance — e.g. Random Forest.
  • Boosting: train sequentially, reweighting misclassified points, reduce bias — e.g. AdaBoost, Gradient Boosting.
  • Stacking: train a meta-learner to combine base predictions.

Yes — linear base classifiers can classify linearly non-separable data. Although each individual member has a linear decision boundary, the ensemble's combined boundary need not be linear:

  • Each linear classifier can be trained on a different weighted version of the data (boosting) or a different feature subspace / bootstrap sample (bagging), so each covers a different region.
  • Weighted voting of several linear boundaries produces a piecewise-linear boundary, which can approximate an arbitrarily complex (non-linear) boundary given enough members.
  • Equivalently, using linear classifiers in different kernel-induced feature spaces gives non-linear boundaries in the original input space.
Final decision: ŷ = sign( Σₜ αₜ hₜ(x) ), hₜ(x) = sign(wₜ·x + bₜ) Each hₜ is linear, yet the signed weighted sum can be non-linear in x — e.g. an XOR pattern (not linearly separable) is learned by two stumps splitting on x1 and x2.

Key requirement: diversity. If all base classifiers make identical errors, combining them gains nothing. Randomisation, different data subsets and different feature views create the diversity that makes the ensemble powerful. Trade-off: increased training cost and reduced interpretability.

Exam tip: Define the ensemble, name bagging/boosting, then answer "yes" explicitly and explain that the combination of linear boundaries is piecewise-linear/non-linear, with diversity as the key ingredient.

Q10

ROC point selection

3 marks

Classifiers A (FPR,TPR) = (0,1), B (1,1), C (1,0.5). Which is perfect? Justify.

Answer

ROC space plots the True Positive Rate (TPR = TP/(TP+FN), vertical axis) against the False Positive Rate (FPR = FP/(FP+TN), horizontal axis). Both lie in [0,1]. The ideal classifier sits at the top-left corner (0,1); the diagonal from (0,0) to (1,1) is random guessing.

A = (0, 1): TPR = 1 → every positive found ; FPR = 0 → no false alarms → PERFECT B = (1, 1): TPR = 1 but FPR = 1 → predicts "positive" for everything (always-positive) C = (1, 0.5): FPR = 1, TPR = 0.5 → all negatives are false positives, only half the positives found → poor, no better than random on negatives

Answer: A is the perfect classifier. It lies at the ideal top-left point of ROC space: it achieves a 100% true-positive rate while producing zero false positives — i.e. it makes no errors at all on either class.

Interpretation of the others: B is a degenerate "always predict positive" rule — it catches all positives but floods the result with false alarms (a classifier of no discriminative value). C is even weaker: it triggers a false alarm on every negative and detects only half the positives. Neither is useful; a model's ROC curve is judged by how close it bows toward A.

Exam tip: State the axes first, then identify (0,1) as perfect and explain both coordinates of A. One line each for B and C completes the justification. (3 marks.)

Q11

Bernoulli, Poisson and geometric MLE

14 marks

a) Coin flipped 4 times gives HHHT: MLE of P(heads). b) Poisson threes: 14, 26, 25, 13 — MLE of λ. c) Geometric x = trials to first success: show p̂ = 1/x.

Answer
General method

For each part we write the pmf, form L = ∏ p(xᵢ|θ), take logs, set dℓ/dθ = 0 and check d²ℓ/dθ² < 0. The data are assumed i.i.d. (independent, identically distributed).

a) Bernoulli coin — H,H,H,T
Let p = P(heads). P(H)=p, P(T)=1−p; three heads, one tail. L(p) = p³(1−p)¹ ℓ(p) = 3 log p + log(1−p) dℓ/dp = 3/p − 1/(1−p) = 0 ⇒ 3(1−p) = p ⇒ p = 3/4 d²ℓ/dp² = −3/p² − 1/(1−p)² < 0 ⇒ maximum p̂ = 3/4 = 0.75 (the sample proportion of heads — the intuitive answer)
b) Poisson mean — 14, 26, 25, 13
P(X=x) = e^(−λ) λ^x / x! L(λ) = ∏ e^(−λ) λ^(xᵢ)/xᵢ! = e^(−nλ) λ^(Σxᵢ) / ∏xᵢ! ℓ(λ) = −nλ + (Σxᵢ) log λ − Σ log(xᵢ!) [last term constant in λ] dℓ/dλ = −n + (Σxᵢ)/λ = 0 ⇒ λ̂ = (Σxᵢ)/n = x̄ Σxᵢ = 14+26+25+13 = 78, n = 4 ⇒ λ̂ = 78/4 = 19.5 d²ℓ/dλ² = −(Σxᵢ)/λ² < 0 ⇒ maximum. The MLE of a Poisson mean is the sample mean.
c) Geometric (x = number of trials up to and including the first success)
P(X=x) = (1−p)^(x−1) p , x = 1,2,3,… [x−1 failures then one success] For one observation x: L(p) = (1−p)^(x−1) p ℓ(p) = (x−1) log(1−p) + log p dℓ/dp = −(x−1)/(1−p) + 1/p = 0 ⇒ (x−1)/(1−p) = 1/p ⇒ p(x−1) = 1−p ⇒ p x = 1 ⇒ p = 1/x d²ℓ/dp² = −(x−1)/(1−p)² − 1/p² < 0 ⇒ maximum Hence p̂ = 1/x — the reciprocal of the observed number of trials.

Interpretation & caveats. In (c) the estimate is intuitive: if the first success took x trials, the estimated success probability per trial is 1/x. Note the two geometric conventions: this one counts trials to success (support 1,2,…, p̂ = 1/x); the alternate counts failures before success (support 0,1,2,…, P(X=x)=(1−p)pˣ, p̂ = x/(x+1)). Always use the pmf stated in the question.

Exam tip (14 marks): For each sub-part show all five steps — pmf, likelihood, log, derivative = 0, second-derivative check — and box the final estimate. The second-derivative check and the note on conventions earn the top marks.

Q12

Geometric pmf MLE + die

14 marks

a) pmf p(x)=θ(1−θ)^(x−1), x=1,2,…: likelihood and MLE of θ. b) 40 die rolls, eight sixes: MLE of P(6).

Answer
a) Geometric pmf — likelihood and MLE of θ

This is the "trials-to-first-success" geometric distribution: P(X=x) = θ(1−θ)^(x−1) for x = 1,2,… Assume a random sample x₁,…,xₙ (i.i.d.).

L(θ) = ∏_{i=1..n} θ(1−θ)^(xᵢ−1) = θⁿ (1−θ)^(Σxᵢ − n) ℓ(θ) = n log θ + (Σxᵢ − n) log(1−θ) dℓ/dθ = n/θ − (Σxᵢ − n)/(1−θ) = 0 ⇒ n(1−θ) = θ(Σxᵢ − n) ⇒ n − nθ = θΣxᵢ − nθ ⇒ n = θ Σxᵢ ⇒ θ̂ = n / Σxᵢ = 1 / x̄ (since x̄ = Σxᵢ/n) d²ℓ/dθ² = −n/θ² − (Σxᵢ − n)/(1−θ)² < 0 (for Σxᵢ > n) ⇒ maximum

Interpretation. The MLE is the reciprocal of the sample mean number of trials — exactly the analogue of part (c) of the previous question. For a single observation (n = 1), θ̂ = 1/x.

b) Die — MLE of P(6)

Each roll is a Bernoulli trial with success = "six", probability p = P(6). With 8 sixes in 40 independent rolls, the number of sixes K ~ Binomial(40, p).

L(p) = p⁸ (1−p)³² ℓ(p) = 8 log p + 32 log(1−p) dℓ/dp = 8/p − 32/(1−p) = 0 ⇒ 8(1−p) = 32p ⇒ 8 = 40p ⇒ p = 8/40 p̂ = 8/40 = 0.2 (the observed proportion of sixes)

This is the general Bernoulli/binomial result: the MLE of a success probability is the observed relative frequency. Here P(6) is estimated as 0.2, considerably higher than the fair-die value 1/6 ≈ 0.167; a hypothesis test would be needed to say whether that difference is significant.

Exam tip (14 marks): Show the full likelihood and log-likelihood and the derivative for both parts. Explicitly connect the answer to "MLE of a probability is the sample proportion," and note the geometric answer θ̂ = 1/x̄ is the reciprocal of the mean.

Q13

ID3 on refund dataset + tree issues

14 marks

a) Compute information gain for each attribute and draw the decision tree (Refund, Marital status, Taxable income). b) What issues do decision-tree algorithms face?

Answer
a) Information gain and decision tree

ID3 builds the tree top-down, choosing at each node the attribute with the highest information gain — the reduction in entropy. Entropy and gain are:

Entropy(S) = − Σ_c p(c) log₂ p(c) Gain(S,A) = Entropy(S) − Σ_{v∈values(A)} (|S_v|/|S|) Entropy(S_v) Root (10 records, 3 "Yes" / 7 "No"): Entropy(S) = −(3/10)log₂(3/10) − (7/10)log₂(7/10) = 0.8813 Gain(Refund) = 0.8813 − 0.6897 = 0.1916 Gain(Marital status) = 0.8813 − 0.6000 = 0.2813 Gain(Taxable income) = 0.8813 − 0.0000 = 0.8813 ← highest → root

Tree. Taxable income has the largest gain, so it is the root. In the given 10-row table each taxable-income value corresponds to a single record, so every branch leads to a pure leaf:

            [ Taxable income ]
        ┌──────┼──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
       t1     t2     t3     t4     t5     t6     t7     t8     t9    t10
        │      │      │      │      │      │      │      │      │      │
       No     No     No     No     Yes    No     No     Yes    No     Yes
   → leaf labels: (No, No, No, No, Yes, No, No, Yes, No, Yes)

For a continuous taxable-income attribute one instead tests candidate thresholds (e.g. ≤ 80k), computes the gain of each binary split and picks the best; the other attributes (Marital status gain 0.2813, Refund gain 0.1916) would be used at deeper nodes if splits were impure.

b) Issues faced by decision-tree algorithms
  • Overfitting: deep trees memorise noise. Remedies: pre-pruning (max depth, min samples per leaf, min gain) and post-pruning (cost-complexity / reduced-error pruning), or use an ensemble (random forest).
  • Instability: a small change in the data can produce a completely different tree; reduced by bagging / random forests.
  • Greedy, non-optimal splits: ID3 chooses the locally best split at each node, which need not give the globally optimal (smallest) tree.
  • Bias toward many-valued attributes: attributes with many distinct values (e.g. an ID) get high gain — use gain ratio (C4.5) or Gini (CART) instead.
  • Axis-aligned boundaries only: oblique / diagonal concepts need many splits; hard to learn smooth functions.
  • Missing values and noisy labels complicate split evaluation; need surrogate splits or imputation.

Exam tip (14 marks): Show the entropy formula, all three gains with the correct numbers, and a sketch of the tree; then give at least four distinct issues, each with a remedy where one exists.

Q14

Flu Naive Bayes + regression on y

14 marks

a) Can the doctor conclude a person with chills=Y, running nose=N, headache=Mild, fever=Y has flu? b) Obtain a linear regression assuming y is the independent variable.

Answer
a) Naive Bayes flu prediction

Naive Bayes applies Bayes' rule with the naive assumption that the attributes are conditionally independent given the class: P(features | class) = ∏ⱼ P(aⱼ | class). We compute an unnormalised score for each class and pick the larger; the common evidence P(features) cancels.

Priors: P(flu)=5/7, P(no flu)=2/7 (5 flu, 2 non-flu training rows) Score(flu) ∝ P(flu)·P(Chills=Y|flu)·P(Running=N|flu)·P(Head=Mild|flu)·P(Fever=Y|flu) = (5/7)(3/5)(2/5)(2/5)(4/5) ≈ 0.0549 Score(no flu) ∝ P(no flu)·(1/2)(2/2)(1/2)(1/2) ≈ 0.0357 0.0549 > 0.0357 ⇒ class = FLU. Yes, the person is predicted to have flu. (Posterior = 0.0549 / (0.0549+0.0357) ≈ 0.606.) With add-1 Laplace smoothing the conclusion is unchanged: 0.0535 vs 0.0268.

The scores are not probabilities (they do not sum to 1 because we dropped the evidence), but their ratio gives the posterior odds. Always compare the unnormalised scores, or normalise them to get a confidence.

b) Linear regression of x on y

Now y is the independent (predictor) variable and x the target — note this is the reverse of the more usual direction, so we fit x̂ = a + b y.

Data: x : 55 60 65 70 80 (mean x̄ = 66) y : 52 54 56 58 62 (mean ȳ = 56.4) b = Σ(y−ȳ)(x−x̄) / Σ(y−ȳ)² = 112 / 44.8 = 2.5 a = x̄ − b·ȳ = 66 − 2.5(56.4) = 66 − 141 = −75 Regression line: x̂ = −75 + 2.5 y Check: y = 60 ⇒ x̂ = −75 + 150 = 75.

Calculation detail. The slope is the cross-product sum divided by the sum of squared deviations of the predictor y: b = Σ(y−ȳ)(x−x̄)/Σ(y−ȳ)² = 112/44.8 = 2.5, and the intercept follows from a = x̄ − bȳ = −75. Always double-check which variable is the predictor: regressing y on x would give a different line, and this question explicitly asks for x on y (so the roles of x and y are reversed relative to the usual convention).

Exam tip (14 marks): For (a) show the priors, the product of five likelihoods for each class, both numeric scores and the decision; mention the independence assumption. For (b) write the model x̂ = a + by, compute both means, the slope, the intercept and verify with a sample point. Box the final numbers.

Q15

Kernels in SVM

14 marks

a) What is a kernel in SVM? Why use kernels? What is the kernel trick? b) Explain different types of kernel functions.

Answer
a) Kernels and the kernel trick

A kernel is a symmetric, positive-semidefinite function K(x, y) = φ(x)·φ(y): it returns the inner product of two data points after mapping them into a (possibly very high-dimensional) feature space via φ. Valid kernels satisfy Mercer's condition; equivalently the Gram matrix [K(xᵢ,xⱼ)] must be positive semi-definite.

Why kernels? Many data sets are not linearly separable in the input space but become separable when mapped into a richer feature space (Cover's theorem). Explicitly computing φ(x) for every point can be prohibitively expensive or even impossible (the RBF kernel maps into an infinite-dimensional space).

SVM dual depends on the data ONLY through dot products: max_α Σαᵢ − ½ ΣᵢΣⱼ αᵢαⱼ yᵢyⱼ (xᵢ·xⱼ) Kernel trick: replace (xᵢ·xⱼ) with K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) → linear algorithm in feature space = non-linear classifier in input space, with no need to compute φ(x) explicitly and no extra cost beyond the n×n Gram matrix.

Benefits: (i) non-linear decision boundaries for the price of a linear solver; (ii) cost scales with the number of samples n, not with the feature-space dimension; (iii) swapping the kernel changes the notion of similarity without redesigning the optimiser; (iv) convex objective ⇒ global optimum, no local minima.

b) Common kernel functions
KernelFormulaProperties / typical use
LinearK(x,y) = x·yNo mapping; linearly separable data; fastest, fewest hyper-parameters.
PolynomialK(x,y) = (x·y + c)^dGlobal polynomial boundaries; degree d and offset c control complexity; can overfit for large d.
RBF / GaussianK(x,y) = exp(−‖x−y‖²/(2σ²))Most popular default; localised, maps to infinite-dimensional space; σ (or γ = 1/2σ²) controls smoothness. Value 1 for identical points, → 0 far apart.
SigmoidK(x,y) = tanh(κ x·y + c)Neural-network-like behaviour; positive-semidefinite only for a restricted parameter range; seldom the first choice.

Selection guidance: start with RBF; use linear for very high-dimensional / large-scale data; a kernel should reflect domain similarity. Hyper-parameters (C, γ, d) are tuned by cross-validation; scaling features first is essential for distance-based kernels.

Exam tip (14 marks): Define K = φ(x)·φ(y), state Mercer/PSD, present the dual and show exactly where the substitution happens (that is the kernel trick). Then give the four kernels with formulas and one use each.

Q16

Backpropagation + activation functions

14 marks

a) Pros and cons of backpropagation. b) Short notes on any four activation functions.

Answer
a) Backpropagation — advantages and disadvantages

Backpropagation computes the gradient of the loss with respect to every weight by applying the chain rule backwards through the network, reusing the intermediate derivatives cached in the forward pass.

ProsCons
Efficient: one forward + one backward pass gives all gradients (cost comparable to one evaluation), avoiding a separate perturbation per weight.Can converge to local minima / saddle points in non-convex loss surfaces.
General: works with any differentiable architecture and loss; the same algorithm underlies all modern deep learning.Vanishing / exploding gradients in deep nets; gradients can shrink or blow up multiplicatively across layers.
Reuses intermediate derivatives, so no repeated recomputation.Sensitive to learning rate, weight initialisation and input scaling; needs careful tuning.
Enables end-to-end learning of millions of parameters.Requires labelled data and many epochs; is not biologically plausible (real neurons do not send exact error signals backwards).

Core equations: δᴸ = (aᴸ − y) ⊙ σ′(zᴸ) at the output; δˡ = ((Wˡ⁺¹)ᵀ δˡ⁺¹) ⊙ σ′(zˡ) for hidden layers; ∂J/∂Wˡ = δˡ (aˡ⁻¹)ᵀ; then W ← W − η ∂J/∂W.

b) Four activation functions
  • Sigmoid σ(z) = 1/(1+e−z): maps ℝ → (0,1); interpretable as a probability, used with cross-entropy / binary outputs. Disadvantage: saturates at both ends → vanishing gradients; not zero-centred.
  • Tanh tanh(z) = (e^z−e−z)/(e^z+e−z) = 2σ(2z)−1: maps ℝ → (−1,1) and is zero-centred, which speeds learning in hidden layers. Disadvantage: still saturates → vanishing gradients.
  • ReLU max(0,z): piecewise linear, cheap to compute, does not saturate for z > 0 (so gradients flow), induces sparse activations; the default for hidden layers. Disadvantage: zero gradient for z < 0 gives "dying ReLU" units that never update; output unbounded above and not zero-centred (Leaky ReLU / ELU mitigate this).
  • Softmax σ(zᵢ) = e^{zᵢ}/Σⱼ e^{zⱼ}: converts a vector of scores into a probability distribution over K classes (outputs sum to 1); used in the output layer for multi-class classification with cross-entropy loss. Degenerates to sigmoid for K=2.

Choice rule: ReLU (or a variant) in hidden layers, sigmoid for binary output, softmax for multi-class output; use sigmoid/tanh only where bounded outputs matter. All must be differentiable so backprop can use them.

Exam tip (14 marks): Give at least three pros and three cons in a table, write the backprop recurrence, then for each activation give its formula, range, one advantage and one disadvantage.

Q17

K-means with Euclidean distance

14 marks

Cluster the eight points into three clusters using Euclidean distance, initial centres A1, B1, C1. Show centres after first round and final clusters.

Answer

Method. Alternate (1) assign each point to the nearest centre using Euclidean distance d = √((x₁−c₁)²+(x₂−c₂)²), and (2) move each centre to the mean of its assigned points. Stop when assignments/centres no longer change. Initial centres: C1=(2,10), C2=(5,8), C3=(1,2).

Points: A1(2,10) A2(2,5) A3(8,4) B1(5,8) B2(7,5) B3(6,4) C1(1,2) C2(4,9) Initial: centre1=(2,10), centre2=(5,8), centre3=(1,2); distance = Euclidean Round 1 — assign to nearest centre, then recompute means: C1 = {A1} → centre (2, 10) C2 = {A3, B1, B2, B3, C2} → centre (6, 6) [mean of (8,4),(5,8),(7,5),(6,4),(4,9)] C3 = {A2, C1} → centre (1.5, 3.5) Round 2: C2 = {A3, B1, B2, B3} → (6.5, 5.25) ; C1 = {A1, C2} → (3, 9.5) Round 3: B1 joins C1 ; C2 = {A3, B2, B3} → (7, 4.33) ; C1 → (11/3, 9) No change after round 3 (converged). FINAL CLUSTERS: C1 = { A1, B1, C2 } centre (3.67, 9.00) C2 = { A3, B2, B3 } centre (7.00, 4.33) C3 = { A2, C1 } centre (1.50, 3.50)

Worked distance illustration (round 1). For A3(8,4): d to c1 = √(36+36)=√72≈8.49; to c2 = √(9+16)=5; to c3 = √(49+4)≈7.28 → assigned to C2. For C2(4,9): d to c1 = √(4+1)=√5≈2.24; to c2 = √(1+1)=√2≈1.41 → nearest C2. Repeating for all eight points gives the round-1 sets shown above.

Objective. Each iteration reduces the within-cluster sum of squares (inertia); convergence to a stationary point is guaranteed, though not necessarily the global optimum — the result depends on the initial centres (k-means++ or multiple restarts help).

Q18

Covariance matrix + PCA

14 marks

a) Find the covariance matrix for X1 = (4,8,13,7), X2 = (11,4,5,14). b) State the PCA algorithm; is PCA supervised?

Answer
a) Covariance matrix
x̄₁ = (4+8+13+7)/4 = 8 ; x̄₂ = (11+4+5+14)/4 = 8.5 Deviations X1: −4, 0, 5, −1 ; X2: 2.5, −4.5, −3.5, 5.5 Squares X1: 16+0+25+1 = 42 ; X2: 6.25+20.25+12.25+30.25 = 69 Cross-products: (−4)(2.5)+(0)(−4.5)+(5)(−3.5)+(−1)(5.5) = −10+0−17.5−5.5 = −33 Using denominator n−1 = 3 (sample covariance): Var(X1) = 42/3 = 14 ; Var(X2) = 69/3 = 23 ; Cov = −33/3 = −11 → [[14, −11], [−11, 23]] Using denominator n = 4 (population / ML covariance): Var(X1) = 42/4 = 10.5 ; Var(X2) = 69/4 = 17.25 ; Cov = −33/4 = −8.25 → [[10.5, −8.25], [−8.25, 17.25]] [Population / ML convention (÷ n = 4): [[10.5, −8.25], [−8.25, 17.25]]. State which convention you use.]

Reading the matrix: the diagonal entries are the variances of X1 and X2; the off-diagonal entries are the covariance. The negative covariance (−11) shows the two variables tend to move in opposite directions. Note the convention: dividing the sums of squares (42, 69) and cross-products (−33) consistently by n−1 = 3 gives [[14,−11],[−11,23]]; dividing by n = 4 would give [[10.5,−8.25],[−8.25,17.25]]. Always state which denominator you use — exam keys vary, and the value [[14,−11],[−11,23]] is the commonly accepted one for this question.

b) PCA algorithm
  1. Standardise the features (subtract mean, divide by standard deviation) so scale does not dominate.
  2. Compute the covariance matrix S of the standardised data.
  3. Find eigenvectors and eigenvalues of S: S v = λ v.
  4. Sort eigenvectors by decreasing eigenvalue (λ₁ ≥ λ₂ ≥ …); the largest eigenvalue gives the direction of maximum variance (PC1).
  5. Keep the top k eigenvectors and project: Z = X·Vₖ. Choose k to retain a target variance fraction Σ_{j≤k} λⱼ / Σⱼ λⱼ (e.g. 95%).

Is PCA supervised? No — it is unsupervised. It uses only the feature matrix X, never the class labels y. It maximises variance, not class separability; the directions it finds need not be the best for classification. (LDA, by contrast, is supervised and maximises between-class vs within-class scatter.) PCA is used for visualisation, compression, noise reduction and as a pre-processing step before a supervised learner.

Exam tip (14 marks): Show the means, deviations and sum-of-squares/cross-products, state the denominator explicitly, give the matrix, then list the PCA steps and clearly say "unsupervised, because no labels are used."

Q19

Confusion metrics + bias

14 marks

a) True labels [T,T,F,T,F,T,F,T], predicted [T,F,T,T,F,F,F,T]. Compute accuracy and precision/recall/F1 for T. b) Characteristics of high-bias, low-variance model.

Answer
a) Confusion matrix and metrics (positive class = T)

Pair the true and predicted labels position by position: TT→TP, TF→FN, FT→FP, FF→TN.

True: T T F T F T F T Predicted: T F T T F F F T Outcome: TP FN FP TP TN FN TN TP Counts: TP = 3, FP = 1, FN = 2, TN = 2 (total 8) Accuracy = (TP+TN)/N = (3+2)/8 = 0.625 Precision = TP/(TP+FP) = 3/(3+1) = 0.75 (of predicted T, how many are T) Recall = TP/(TP+FN) = 3/(3+2) = 0.60 (of actual T, how many found) F1 = 2·Precision·Recall/(Precision+Recall) = 2(0.75)(0.60)/(0.75+0.60) = 0.9/1.35 ≈ 0.667

F1 is the harmonic mean of precision and recall; it is useful when there is a trade-off between the two and class imbalance makes accuracy misleading. Specificity = TN/(TN+FP) = 2/3 ≈ 0.667.

b) High-bias, low-variance model

This is the underfitting regime of the bias–variance trade-off:

  • High bias: the model's average prediction is far from the true function — it makes strong, overly simple assumptions (e.g. a straight line through curved data) and ignores informative features.
  • Low variance: the fitted model changes very little when trained on different samples — predictions are stable but consistently wrong.
  • Symptom: high training error and similarly high test error; only a small train–test gap (unlike overfitting, where the gap is large).
  • Remedies: add features / interaction or polynomial terms, increase model capacity, reduce regularisation, train longer, improve optimisation, or reduce noise in the data.

Contrast: low bias + high variance = overfitting (low training error, high test error, large gap) — cured by regularisation, more data, bagging or early stopping.

Exam tip (14 marks): Build the confusion matrix first (TP=3, FP=1, FN=2, TN=2), then each metric with its formula, then describe underfitting with the training/test-error pattern and at least three remedies.

Q20

Linkage dendrograms + search metrics

14 marks

a) Single and complete link agglomerative clustering for the 4×4 distance matrix; show dendrograms. b) 80 records, 55 relevant, 50 retrieved, 40 of those relevant: confusion matrix, precision and recall.

Answer
a) Agglomerative clustering — single vs complete linkage

Agglomerative clustering starts with each point as its own cluster and repeatedly merges the closest pair. Single linkage uses the minimum inter-point distance between clusters (d(min)); complete linkage uses the maximum (d(max)).

Distances: d(A,B)=1, d(A,C)=4, d(A,D)=5, d(B,C)=2, d(B,D)=6, d(C,D)=3 Single linkage (merge at the minimum distance): A+B @1 → (AB) ; d((AB),C)=min(4,2)=2 → (ABC) @2 ; d((ABC),D)=min(5,6,3)=3 → (ABCD) @3 (chaining effect) Complete linkage (merge at the maximum distance): A+B @1, C+D @3 ; d((AB),(CD)) = max(4,5,2,6) = 6 → merge @6 Dendrograms (height = merge distance): single: complete: ┌── D @3 ┌────── @6 ──┐ ┌─┤ │ ┌─ A ─┐ │ │ └──┐ │ │ B ─┘ │ │ ┌─┴─ C @2 │ └──────────┤ │ │ │ ┌─ C ─┐ │ A B A │ D ─┘ │ B C D (truncated sketch; A,B merge @1; C,D @3)

Single linkage produces long "chains" (the classic chaining phenomenon) and can ignore cluster compactness; complete linkage favours compact, spherical clusters and is more sensitive to outliers.

b) Information-retrieval confusion matrix
Total records N = 80 ; relevant in DB = 55 ; retrieved = 50 ; relevant & retrieved = 40 | Retrieved | Not retrieved | Total Relevant | TP = 40 | FN = 55−40=15 | 55 Not relevant | FP = 10 | TN = 80−55−10 = 15 | 25 Total | 50 | 30 | 80 TP = 40, FP = 50−40 = 10, FN = 55−40 = 15, TN = 80−40−10−15 = 15 Precision = TP/(TP+FP) = 40/50 = 0.80 (fraction of retrieved docs that are relevant) Recall = TP/(TP+FN) = 40/55 ≈ 0.727 (fraction of relevant docs that are retrieved)

(Accuracy here = (TP+TN)/N = (40+15)/80 = 0.6875, and F1 = 2·0.80·0.727/(0.80+0.727) ≈ 0.762, if requested.) Precision and recall trade off against each other as the retrieval threshold is varied; the F1 or the precision–recall curve summarises the trade-off.
