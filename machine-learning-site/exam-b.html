Q1

MLE vs MAP

3 marks

Differentiate between MLE and MAP estimation.

Answer

Both are point-estimation rules for the parameter θ of a statistical model given data D = {x₁,…,xₙ}; they differ in whether they use prior knowledge.

MLE: θ̂ = argmax_θ P(D | θ) — maximises the likelihood alone MAP: θ̂ = argmax_θ P(D | θ)·P(θ) — maximises likelihood × prior = argmax_θ [ log P(D | θ) + log P(θ) ]
AspectMLEMAP
ObjectiveLikelihood P(D|θ)Posterior P(θ|D) ∝ P(D|θ)P(θ)
Prior knowledgeIgnores it (implicit uniform prior)Incorporates it through P(θ)
Small dataCan overfit / be extremePrior regularises, pulls toward sensible values
Relation to regularisationNo regularisationGaussian prior ⇔ L2 (ridge); Laplace prior ⇔ L1 (lasso)
Example (Bernoulli, h heads in n tosses)p̂ = h/nwith Beta(α,β) prior: p̂ = (h+α−1)/(n+α+β−2)

Relationship. MAP generalises MLE: MLE is the special case of MAP with a uniform (flat) prior P(θ) ∝ constant, since the prior then drops out of the argmax. As n → ∞ the likelihood dominates the prior and the two estimates converge. Computationally, MAP's extra log-prior term is often simple and convex, giving a regularised objective.

Exam tip: Write both definitions, state that MLE = uniform-prior MAP, give the regularisation link, and use the Beta/Bernoulli example if space allows.

Q2

Geometric MLE

3 marks

Find the ML estimate of p in f(x) = (1−p)pˣ, x = 1,2,3,…

Answer

The given pmf counts the number of failures before the first success (support 0,1,2,… normally; the question writes x = 1,2,…, so we follow its stated pmf and support). Use the pmf as written.

P(X=x) = (1−p) pˣ L(p) = (1−p) pˣ (single observation; for n i.i.d. points raise to the product) ℓ(p) = log(1−p) + x log p dℓ/dp = −1/(1−p) + x/p = 0 ⇒ x(1−p) = p ⇒ x − xp = p ⇒ x = p(x+1) ⇒ p̂ = x/(x+1) d²ℓ/dp² = −1/(1−p)² − x/p² < 0 ⇒ maximum

Interpretation & convention warning. This is the "failures-before-success" geometric: if x failures precede the success, the estimated success probability is x/(x+1) (number of failures over total trials). If instead x counts trials up to and including the success, the pmf is P(X=x) = (1−p)^(x−1) p and the MLE is p̂ = 1/x. Always derive from the pmf given in the question — using the wrong convention is the most common error here.

Exam tip: Show the likelihood, log-likelihood, derivative, solution and second-derivative check; add the one-line note contrasting the two geometric conventions to show mastery.

Q3

Gradient descent principle

3 marks

Specify the basic principle of the gradient descent algorithm.

Answer

Principle. The gradient ∇J(θ) of a loss function points in the direction of steepest increase of J at θ. To minimise J, repeatedly step in the opposite direction, with step size (learning rate) η:

θ ← θ − η ∇J(θ) For linear regression with J(θ) = 1/(2m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²: ∂J/∂θⱼ = (1/m) Σᵢ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾) xⱼ⁽ⁱ⁾ θⱼ ← θⱼ − η (1/m) Σᵢ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾) xⱼ⁽ⁱ⁾

Intuition. Imagine descending a hill blindfolded: at each point feel the slope (the gradient) and take a small step downhill. Because J is convex for ordinary least squares, this converges to the global minimum; for non-convex neural-network losses it converges to a local minimum / saddle point.

Variants. Batch GD uses all m examples per step (stable, accurate, slow); stochastic GD uses one example (fast, noisy); mini-batch uses a small subset (the practical compromise). Momentum, Adam and adaptive rates improve speed and stability; feature scaling / normalisation is important because unequal scales skew the gradient.

Learning-rate trade-off: η too large → overshoot, oscillation or divergence; η too small → painfully slow convergence. Stop when ‖Δθ‖ or ‖∇J‖ falls below a tolerance, or after a fixed number of epochs.

Exam tip: State the update rule, explain "move opposite the gradient because it is steepest ascent," give the derivative for linear regression, and mention η and the three variants.

Q4

Quadratic regression

3 marks

Find a quadratic regression model for x = 3,4,5,6,7; y = 2.5,3.2,3.8,6.5,11.5.

Answer

A quadratic regression fits ŷ = a + b x + c x² by least squares, minimising Σ(yᵢ − ŷᵢ)². It is still linear in the parameters (a, b, c), so we solve the normal equations XᵀXβ = Xᵀy with the design matrix having columns [1, x, x²].

Data: x = 3, 4, 5, 6, 7 ; y = 2.5, 3.2, 3.8, 6.5, 11.5 Design matrix rows: [1, xᵢ, xᵢ²] Normal equations: XᵀX β = Xᵀy , β = (a, b, c)ᵀ Solve the 3×3 system (e.g. by Gaussian elimination or numpy.polyfit): ŷ = 12.4286 − 5.5129 x + 0.7643 x²

Checks / interpretation. The positive coefficient c = 0.7643 means the fitted curve is an upward-opening parabola, consistent with y accelerating from 2.5 to 11.5 as x goes 3 → 7. Evaluate at x = 5: ŷ ≈ 12.4286 − 27.5645 + 19.1075 ≈ 3.97, close to the observed 3.8. Compare with a straight-line fit via R² or residual plots; if the residuals show curvature, the quadratic term is justified. (Use adjusted R² or a t-test on c to avoid over-fitting with higher degrees.)

Exam tip: Write the model form, set up XᵀXβ = Xᵀy, quote the coefficients, and check one fitted value. Stating that the fit is linear in the parameters (so least squares applies) earns a method mark.

Q5

Why kernels instead of direct projection

3 marks

Why use kernels to model a projection into feature space instead of projecting the dataset directly?

Answer

Both approaches give a non-linear classifier, but the kernel route avoids forming the mapped vectors φ(x) explicitly.

  • No explicit high-dimensional vectors. The kernel computes K(x,y) = φ(x)·φ(y) directly from the original coordinates. For the RBF kernel φ lives in an infinite-dimensional space, which could never be materialised on a computer; the kernel evaluates its inner product in O(d) time in the input dimension d.
  • Computational cost depends on n, not on the feature dimension. The SVM dual needs only the n×n Gram matrix of pairwise kernels. Direct projection would require storing and manipulating D-dimensional vectors (D ≫ d) for every sample and every new test point — the curse of dimensionality.
  • Only inner products appear in the dual. Replacing xᵢ·xⱼ with K(xᵢ,xⱼ) is a one-line change that yields a non-linear boundary while reusing the same convex optimiser — no new learning algorithm is needed.
  • Flexibility. Different kernels encode different notions of similarity (polynomial, RBF, sigmoid); the model class can be changed without redesigning the learner or re-deriving the optimisation.
Direct: x → φ(x) ∈ ℝ^D → dot products φ(xᵢ)·φ(xⱼ) (must compute/store φ) Kernel: K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) computed from (xᵢ,xⱼ) (φ never formed)

Caveat. Kernels are not free: building the Gram matrix is O(n²) in time and memory, which is why kernel methods scale less well than explicit feature maps (e.g. random Fourier features) for very large n. Mercer's condition (PSD Gram matrix) must hold for the kernel to correspond to some feature space.

Exam tip: Emphasise "infinite-dimensional RBF space" and "cost scales with n, not D" — these are the two marks-winning points. Mention Mercer's condition as a bonus.

Q6

ReLU vs tanh

3 marks

ReLU is often used instead of tanh. Draw both and give an advantage and a disadvantage of ReLU.

Answer

Both are element-wise non-linearities used in hidden layers; the choice affects how gradients flow during backpropagation.

ReLU(z) = max(0, z) tanh(z) = (e^z − e^(−z))/(e^z + e^(−z)) ReLU tanh │ / │ ┌───── +1 │ / │ ┌──┘ │ / │ / └─────┼────── z ──┼────────── z / │ / │ (flat 0 for z<0; linear z for z>0) └──┘ smooth S-curve, −1 → +1 through 0 ReLU': 0 for z<0, 1 for z>0 tanh': 1 − tanh²(z) ∈ (0,1]

Advantage of ReLU. For z > 0 the derivative is exactly 1, so the gradient does not saturate/vanish; this lets very deep networks train effectively. ReLU is also cheap (a max operation) and induces sparse activations (about half the units are zero), which can improve generalisation and efficiency.

Disadvantage of ReLU. For z < 0 the gradient is exactly zero, so a unit can "die" — once pushed into the negative region it never updates again (dying ReLU). Its outputs are also not zero-centred and are unbounded above, unlike tanh's bounded (−1,1) zero-centred range; Leaky ReLU and ELU address these issues.

Why it replaced tanh. tanh saturates at both tails where its derivative → 0, causing vanishing gradients in deep nets; ReLU's constant positive slope avoids this on the positive side. In practice ReLU (or a variant) is the default for hidden layers, softmax/sigmoid for outputs.

Exam tip: Sketch both curves with axes and labelled ranges, then give one clear advantage (no saturation / sparse / fast) and one disadvantage (dying ReLU / not zero-centred) with the derivative behaviour to justify them.

Q7

Image similarity measure

3 marks

Find a similarity measure to compare feature vectors of two images. Justify.

Answer

Cosine similarity is a strong default for comparing image feature vectors (descriptors such as colour histograms, HOG, or CNN embeddings).

cos(θ) = (x·y) / (‖x‖ ‖y‖) = Σᵢ xᵢ yᵢ / (√Σᵢ xᵢ² · √Σᵢ yᵢ²) Range: −1 (opposite) … 0 (orthogonal/unrelated) … +1 (identical direction)

Justification.

  • It measures the angle between descriptors, so it is invariant to overall scale/brightness: one photo may be brighter (larger vector magnitude) but have the same content — cosine gives similarity 1, whereas raw Euclidean distance would report a large difference.
  • It is normalised to [−1,1], giving a comparable score across images regardless of vector length.
  • For non-negative features (histograms, bag-of-visual-words) the score lies in [0,1] and is quick to compute as a dot product of unit-normalised vectors.

Alternatives and when to use them. Euclidean distance √Σ(xᵢ−yᵢ)² (or MSE) is appropriate when absolute magnitudes carry information; histogram intersection or Bhattacharyya/Hellinger distance is common for colour histograms; SSIM compares structural information and is closer to human perception; for learned embeddings, cosine is standard. If illumination differences are irrelevant, normalise vectors first (unit-length) and then Euclidean and cosine rankings become equivalent.

Exam tip: Give the formula, justify with brightness/scale invariance, and mention one alternative (Euclidean or SSIM) with the condition under which it is preferred.

Q8

Agglomerative clustering

3 marks

Describe agglomerative hierarchical clustering.

Answer

Agglomerative clustering is a bottom-up hierarchical method: it begins with every object in its own singleton cluster and repeatedly merges the closest pair until a single cluster remains (or a stopping criterion is met).

  1. Start: n clusters, one per object.
  2. Compute inter-cluster distances using a linkage criterion:
    • single linkage = minimum distance between any two members (produces chains);
    • complete linkage = maximum distance (compact clusters);
    • average linkage = mean pairwise distance;
    • Ward's method = increase in within-cluster sum of squares on merging.
  3. Merge the closest pair of clusters.
  4. Update the distance matrix (Lance–Williams recurrence) and repeat step 3 until one cluster remains.
Output = a dendrogram (tree of nested merges, height = merge distance). Cut the dendrogram at height h (or for K clusters) to obtain a flat partition. Complexity: O(n³) time, O(n²) memory — costly for large n.

Properties. It is deterministic (no random initialisation), requires no preset K (choose K by cutting the tree), and yields a useful visualisation. However, merges are irreversible (no backtracking), it is cubic in n, and it is sensitive to noise/outliers and to the choice of linkage. Contrast with divisive (top-down) clustering, which starts with all points together and splits recursively, and with K-means, which needs K and produces flat clusters.

Exam tip: Give the four steps in order, name the linkage options, state that the output is a dendrogram cut at a chosen height, and list one strength and one limitation.

Q9

Choosing between classifiers

3 marks

Classifier A: 100% train, 70% test. Classifier B: 70% train, 75% test. Which is better?

Answer

B is better. The purpose of a classifier is to generalise to unseen data, so the test accuracy is the figure of merit: B's 75% exceeds A's 70%.

A: train 100%, test 70% → gap = 30 points ⇒ overfitting (high variance, low bias) B: train 70%, test 75% → train ≤ test, gap ≈ 0 ⇒ robust / well-generalising

Diagnosis of A. Perfect training accuracy with much worse test accuracy is the classic signature of overfitting: the model has memorised the training set, including its noise, rather than learning the underlying pattern. Its variance is high — a different training sample would give a very different fitted model. Remedies: regularise, reduce model complexity / depth, prune, add more training data, apply dropout or early stopping, and re-evaluate with cross-validation.

Diagnosis of B. B's test score slightly exceeds its train score, which is perfectly normal with small or noisy samples (the test set may happen to be easier, or the training score is measured before full convergence). A near-zero or negative train–test gap shows B has not memorised the data; it has lower variance and will generalise more reliably.

Caveats. Accuracy alone can be misleading if classes are imbalanced — check the confusion matrix, precision/recall and ROC-AUC, and report results with cross-validation / confidence intervals to ensure the difference (75% vs 70%) is not just sampling noise.

Exam tip: Choose B, justify with test accuracy and the train–test gap, name A's problem as overfitting/high variance, and give at least two remedies. Add the imbalance caveat for top marks.

Q10

AUC

3 marks

State Area under curve in machine learning. Specify the significance of AUC.

Answer

AUC (Area Under the ROC Curve) is the integral of the ROC curve — True Positive Rate plotted against False Positive Rate as the classification threshold is swept from 0 to 1. It lies in [0,1].

AUC = ∫₀¹ TPR(FPR) dFPR Probabilistic meaning: AUC = P(score of a random positive > score of a random negative) 1 → perfect ranking 0.5 → random guessing (diagonal) <0.5 → worse than random (invert the classifier to exceed 0.5)

Significance.

  • Threshold-independent: a single number summarising performance over all decision thresholds, so no arbitrary cut-off needs to be chosen.
  • Ranking quality: it measures how well the model orders positives above negatives, which matters for retrieval and ranking tasks.
  • Robust to class imbalance: unlike accuracy, TPR and FPR condition on the true class, so AUC remains informative when one class is rare.
  • Comparable: allows comparison of different classifiers; higher AUC is better, and a convex hull of ROC points gives the best achievable operating points.

Limits. AUC ignores calibration (predicted probabilities need not be accurate) and can look optimistic for very imbalanced data; precision–recall AUC is often preferred when positives are extremely rare. Rule of thumb: 0.5 random, 0.6–0.7 poor, 0.7–0.8 acceptable, 0.8–0.9 good, >0.9 excellent.

Exam tip: Define AUC as area under ROC, give the probabilistic interpretation, the 1 / 0.5 benchmark values and at least two significance points (threshold-free, imbalance-robust, ranking).

Q11

Class vs regression + MLE of θ

14 marks

a) Distinguish classification and regression with an example. b) pmf P(0)=2θ/3, P(1)=θ/3, P(2)=2(1−θ)/3, P(3)=(1−θ)/3; observations (3,0,2,1,3,2,1,0,2,1). Find MLE of θ.

Answer
a) Classification vs regression

Classification predicts a discrete class label from a finite set (e.g. spam / ham, digit 0–9, pass / fail); the output is categorical, evaluation uses accuracy / precision / recall / ROC-AUC, and a suitable model is logistic regression, SVM or Naive Bayes. Regression predicts a continuous real-valued quantity (e.g. house price, temperature, stock price); evaluation uses MSE / RMSE / R², with linear regression or SVR as typical models. Example: predicting whether a tumour is malignant is classification; predicting its size in millimetres is regression. The same feature vector can feed either, depending on the target type.

b) MLE of θ

Count the observations: (3,0,2,1,3,2,1,0,2,1) → n₀ = 2 (two 0s), n₁ = 3 (three 1s), n₂ = 3 (three 2s), n₃ = 2 (two 3s); total 10. Assuming i.i.d. draws, the likelihood is the product of the corresponding probabilities.

L(θ) = [P(0)]² [P(1)]³ [P(2)]³ [P(3)]² = (2θ/3)² (θ/3)³ (2(1−θ)/3)³ ((1−θ)/3)² ℓ(θ) = const + (2+3) log θ + (3+2) log(1−θ) = const + 5 log θ + 5 log(1−θ) dℓ/dθ = 5/θ − 5/(1−θ) = 0 ⇒ 5(1−θ) = 5θ ⇒ θ̂ = 0.5 d²ℓ/dθ² = −5/θ² − 5/(1−θ)² < 0 ⇒ maximum

Why exactly one half? The exponent of θ is n₀ + n₁ = 5 (probabilities of 0 and 1 are proportional to θ) and the exponent of (1−θ) is n₂ + n₃ = 5 (probabilities of 2 and 3 are proportional to 1−θ). With equal exponents the estimate is 5/(5+5) = 0.5. More generally, for a multinomial with two probability groups, θ̂ = (count in θ-group) / (total count) = 5/10.

Exam tip (14 marks): For (a) give the discrete/continuous distinction, one example and metrics. For (b) tabulate the counts, write L(θ) as a product of powers, take logs, differentiate, solve and verify the maximum; note why the equal exponents give 0.5.

Q12

Learning paradigms + Naive Bayes parameters

14 marks

a) Describe supervised, unsupervised and reinforcement learning with examples. b) Three classes y ∈ {0,1,2}, three binary attributes X₁,X₂,X₃: how many parameters does Naive Bayes need?

Answer
a) Three learning paradigms
ParadigmData / feedbackGoalExamples
SupervisedLabelled pairs (X, y)Learn f: X → y to predict labels for new XClassification (spam detection), regression (price prediction), SVM, decision trees
UnsupervisedUnlabelled X onlyDiscover hidden structure: clusters, components, low-dim structureK-means, hierarchical clustering, PCA, GMM/EM, association rules
ReinforcementAn agent takes actions in an environment and receives scalar rewardsLearn a policy π: state → action maximising cumulative discounted returnGame playing (AlphaGo), robotics, Q-learning, self-driving

The key distinction is the feedback: supervised learning gets the correct answer for each example, unsupervised learning gets no answer at all, and reinforcement learning gets a delayed evaluative reward rather than an instruction.

b) Naive Bayes parameter count

A Naive Bayes model stores (i) class priors P(y), and (ii) conditional probabilities P(Xⱼ | y) for each attribute j and class y, exploiting the naive conditional-independence assumption.

Class priors P(y): 3 values (one per class) but they sum to 1 → 2 free parameters. Conditionals P(Xⱼ = value | y): 3 classes × 3 attributes × 2 values = 18 table entries. For each (class, attribute) pair the two values sum to 1 → 3×3 = 9 constraints → 18 − 9 = 9 free parameters. Total free parameters = 2 + 9 = 11. (Equivalently: 21 table entries in all minus 10 sum-to-1 constraints = 11.)

Why the count matters. Naive Bayes' parameter count grows linearly in the number of attributes (d), unlike a full joint model which needs exponentially many (2ᵈ per class). This is exactly the simplification bought by the naive independence assumption, and it is why Naive Bayes works well with high-dimensional data and small training sets.

Exam tip (14 marks): For (a) give a definition, the data/feedback, one example and the goal for each paradigm. For (b) count priors and conditionals separately, subtract the sum-to-one constraints, and state the total 11 clearly.

Q13

ID3 + regression coefficients

14 marks

a) Identify the first splitting attribute by ID3 (Age, Competition, Type). b) For X=(3,9,11,5,2)ᵀ and Y=(1,8,11,4,3)ᵀ evaluate the regression coefficients.

Answer
a) ID3 — first splitting attribute

ID3 selects the attribute with the highest information gain, Gain(S,A) = Entropy(S) − Σᵥ (|Sᵥ|/|S|)·Entropy(Sᵥ), where Entropy(S) = −Σ_c p(c) log₂ p(c).

Root: 4 positive / 6 negative out of 10 Entropy(S) = −(4/10)log₂(4/10) − (6/10)log₂(6/10) = 1.0000 Gain(Age) = 1.0000 − 0.4000 = 0.6000 ← highest → first split Gain(Competition) = 1.0000 − 0.8755 = 0.1245 Gain(Type) = 1.0000 − 1.0000 = 0.0000 (no information) First split: AGE. (The Age=Mild and Age=New branches are then split further on Competition, since Type carries no information.)

Because Gain(Type) = 0, Type is useless at the root: knowing it does not reduce uncertainty about the class at all.

b) Regression coefficients

Fit ŷ = a + b x by ordinary least squares: b = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² and a = ȳ − b x̄.

X = (3,9,11,5,2)ᵀ ; Y = (1,8,11,4,3)ᵀ ; n = 5 x̄ = (3+9+11+5+2)/5 = 30/5 = 6 ȳ = (1+8+11+4+3)/5 = 27/5 = 5.4 Σ(x−x̄)(y−ȳ) = 27 ; Σ(x−x̄)² = 27 b = 27/27 = 1.0 a = ȳ − b x̄ = 5.4 − 1.0(6) = −0.6 ŷ = −0.6 + x

Check: at x = 9, ŷ = 8.4 versus observed 8 — close; at x = 11, ŷ = 10.4 versus 11. The slope of 1 means each unit increase in x raises the prediction by one unit. (If required, R² = [Σ(ŷ−ȳ)²]/[Σ(y−ȳ)²] can be computed from the same sums.)

Exam tip (14 marks): Show the entropy/gain formulas and all three gains with the split decision; for the regression show both means, the two sums, the slope, the intercept and one check value.

Q14

Flu Naive Bayes + gradient descent cost

14 marks

a) Can a person with chills=Y, fever=Y, headache=Mild, running nose=N have flu? b) h(x)=θ₀+θ₁x, J=1/(2m)Σ(h(x⁽ⁱ⁾)−y⁽ⁱ⁾)² for (3,2),(1,2),(0,1),(4,3): find h(2) at (0,1.5), J(0,1), and interpret J=0.

Answer
a) Naive Bayes flu classification

With 5 flu and 2 no-flu training rows, and assuming conditional independence of symptoms given the class, compare the unnormalised posteriors (the evidence P(symptoms) cancels):

Priors: P(flu)=5/7, P(no flu)=2/7 Scores for (chills=Y, fever=Y, headache=Mild, running nose=N): Flu score ∝ (5/7)(3/5)(2/5)(2/5)(4/5) ≈ 0.0549 No-flu score ∝ (2/7)(1/2)(2/2)(1/2)(1/2) ≈ 0.0357 0.0549 > 0.0357 ⇒ YES, flu is predicted (same conclusion under Laplace smoothing).

The normalised posterior is 0.0549/(0.0549+0.0357) ≈ 0.606, i.e. about 61% confidence in flu.

b) Gradient-descent quantities

Model h(x) = θ₀ + θ₁ x; cost J(θ₀,θ₁) = 1/(2m) Σᵢ (h(x⁽ⁱ⁾) − y⁽ⁱ⁾)² with m = 4 data points (3,2), (1,2), (0,1), (4,3).

1) At θ = (0, 1.5): h(2) = 0 + 1.5·2 = 3 2) At θ = (0, 1) the predictions are h(x) = x: (3→3, 1→1, 0→0, 4→4) vs targets (2,2,1,3) J(0,1) = 1/(2·4)[ (3−2)² + (1−2)² + (0−1)² + (4−3)² ] = 1/8 [1 + 1 + 1 + 1] = 4/8 = 0.5 3) J = 0 ⇔ every squared error is zero ⇔ h(x⁽ⁱ⁾) = y⁽ⁱ⁾ for all i: a perfect fit through all data points — the global minimum of the (convex) quadratic cost surface, reached when gradient descent converges.

Gradient check. ∂J/∂θⱼ = (1/m) Σᵢ (h(x⁽ⁱ⁾) − y⁽ⁱ⁾) xⱼ⁽ⁱ⁾ (with x₀⁽ⁱ⁾ = 1), so one GD step from (0,1) with learning rate η updates θ towards reducing the residual sum 4. Note that J is convex (a positive semi-definite quadratic bowl) so gradient descent reaches this global minimum.

Exam tip (14 marks): For (a) show priors, both products of likelihoods, both scores and the decision. For (b) list the four predictions explicitly, sum the squared errors, divide by 2m, and state clearly that J = 0 means perfect fit / global minimum.

Q15

Backpropagation + neuron output

14 marks

a) Perform one iteration of forward and backward propagation for the two-sample ANN with one hidden layer. b) Compute the output of a three-input neuron with x=(0.8,0.6,0.4), w=(0.2,0.1,−0.3), b=0.35 using sigmoid.

Answer
a) One iteration of forward and backward propagation

Set small random initial weights/biases (e.g. uniform in [−0.5, 0.5]). For each of the two samples carry out the following; accumulate gradients for a batch or apply immediately for stochastic updates.

1. Forward pass (per sample): z_h = W_h x + b_h ; h = σ(z_h) (hidden activations) z_o = W_o h + b_o ; ŷ = σ(z_o) (output activation) 2. Output error signal (for MSE loss L = ½(y − ŷ)²): δ_o = (y − ŷ) · σ′(z_o) where σ′(z) = σ(z)(1 − σ(z)) (with cross-entropy output loss the σ′ factor cancels and δ_o = ŷ − y) 3. Back-propagate to hidden layer (chain rule): δ_h = (W_oᵀ δ_o) · σ′(z_h) 4. Gradients and update (learning rate η): ∂L/∂W_o = δ_o hᵀ , ∂L/∂b_o = δ_o ∂L/∂W_h = δ_h xᵀ , ∂L/∂b_h = δ_h W ← W − η ∂L/∂W , b ← b − η ∂L/∂b 5. Repeat for sample 2 with the updated weights (or sum gradients over both samples for a batch update), then move to the next epoch.

Key idea. The chain rule factorises each parameter's gradient into a sensitivity δ from layers downstream times a local derivative. Caching the forward activations makes the whole backward sweep cost about the same as one forward pass, independent of the number of weights (modulo matrix sizes). This is what makes training deep networks tractable.

b) Three-input neuron output
x = (0.8, 0.6, 0.4) ; w = (0.2, 0.1, −0.3) ; b = 0.35 z = Σᵢ wᵢ xᵢ + b = 0.8(0.2) + 0.6(0.1) + 0.4(−0.3) + 0.35 = 0.16 + 0.06 − 0.12 + 0.35 = 0.45 y = σ(z) = 1/(1 + e^(−0.45)) ≈ 0.6106

The bias shifts the activation threshold; the negative weight on x₃ subtracts from the net input. Since z = 0.45 > 0, the sigmoid output exceeds 0.5 (0.6106), meaning the neuron would "fire" under a 0.5 threshold.

Q16

SVM formulation + backprop idea

14 marks

a) State the mathematical formulation of the SVM problem and outline the solution method. b) Show the basic idea of backpropagation.

Answer
a) SVM formulation and solution

Soft-margin primal (allows misclassification via slack variables ξᵢ, penalised by C):

Primal: min_{w,b,ξ} ½‖w‖² + C Σᵢ ξᵢ s.t. yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ , ξᵢ ≥ 0 for i = 1,…,n Dual: max_α Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ K(xᵢ, xⱼ) s.t. 0 ≤ αᵢ ≤ C and Σᵢ αᵢ yᵢ = 0 After solving: w = Σᵢ αᵢ yᵢ φ(xᵢ); support vectors have αᵢ > 0; b from a support vector on the margin; classify with ŷ = sign( Σᵢ αᵢ yᵢ K(xᵢ, x) + b ).

Solution method. The dual is a convex quadratic program with linear constraints — the global optimum is guaranteed. It is solved with specialised algorithms such as SMO (sequential minimal optimisation), which breaks the QP into tiny two-variable subproblems solvable analytically. The ½‖w‖² term maximises the margin (2/‖w‖), C trades margin width against training errors, and the kernel K handles non-linear boundaries. For large datasets, linearSVM / hinge-loss gradient descent is preferred.

b) Basic idea of backpropagation

Backpropagation computes gradients of the loss with respect to all weights by applying the chain rule backwards through the layered network:

1. Forward pass: compute each activation aˡ = σ(Wˡ aˡ⁻¹ + bˡ) and the loss J. 2. Output sensitivity: δᴸ = ∂J/∂zᴸ (e.g. (ŷ−y)⊙σ′(zᴸ) for MSE). 3. Backward recurrence: δˡ = ((Wˡ⁺¹)ᵀ δˡ⁺¹) ⊙ σ′(zˡ). 4. Parameter gradients: ∂J/∂Wˡ = δˡ (aˡ⁻¹)ᵀ , ∂J/∂bˡ = δˡ. 5. Update: Wˡ ← Wˡ − η ∂J/∂Wˡ (and similarly bˡ).

One backward sweep supplies the gradient for every parameter — far cheaper than perturbing each weight individually. The algorithm requires differentiable activations and is the training engine of essentially all neural networks; its limitations are local minima and vanishing/exploding gradients.

Exam tip (14 marks): State both primal and dual SVM with constraints, name SMO and the support vectors, give the prediction rule, then write the backprop recurrence and explain the chain-rule efficiency in one or two sentences.

a) K-means with k = 2

Choose the two farthest-apart points as initial centres: (2,0) and (3,5) (distance √26 ≈ 5.1, the largest pairwise separation). Assign each point to the nearer centre (Euclidean), then recompute the means.

Initial centres: c1 = (2,0), c2 = (3,5) Round 1: C1 = {(2,0),(1,2),(2,2),(2,3)} → centre (2, 1.5) C2 = {(3,2),(3,3),(2,4),(3,4),(4,4),(3,5)} → centre (17/6, 23/6) Round 2: identical assignments → converged. Q18

PCA reduction + distances

14 marks

a) Use PCA to reduce the 2-D data (X = 2,3,7; Y = 11,14,26) to one dimension. b) Compute Euclidean and Manhattan distance between (22,1,42,10) and (20,0,36,8).

Answer
a) PCA to one dimension

Step 1 — centre the data by subtracting the feature means.

Points: (2,11), (3,14), (7,26) Means: x̄ = (2+3+7)/3 = 4 , ȳ = (11+14+26)/3 = 17 Centred: (2−4, 11−17) = (−2,−6) ; (−1,−3) ; (3,9) All centred points satisfy y = 3x — perfectly collinear ⇒ a single PC captures 100% variance. The direction of the line is (1,3); unit vector = (1,3)/√(1²+3²) = (1,3)/√10 1-D scores z = v·(centred point): (−2,−6): (−2)(1)+(−6)(3))/√10 = −20/√10 ≈ −6.325 (−1,−3): −10/√10 ≈ −3.162 (3, 9): 30/√10 ≈ 9.487

Because the three centred points lie exactly on a line, the second eigenvalue is zero and the first PC explains all the variance — the 2-D data are losslessly represented by these 1-D scores. In general you would form the covariance matrix, take the top eigenvector and project; here collinearity makes the direction obvious.

b) Euclidean and Manhattan distances
p = (22,1,42,10) , q = (20,0,36,8) Per-coordinate differences: |22−20|=2, |1−0|=1, |42−36|=6, |10−8|=2 Euclidean (L2): √(2² + 1² + 6² + 2²) = √(4+1+36+4) = √45 ≈ 6.708 Manhattan (L1): 2 + 1 + 6 + 2 = 11

Notes. Euclidean distance is the straight-line length and is smooth/differentiable, so it is the default for clustering and K-means; Manhattan distance sums absolute differences and is more robust to outliers, preferred in grid-like settings (e.g. city blocks). The general Minkowski family is (Σ|pᵢ−qᵢ|^r)^(1/r): r = 1 gives Manhattan, r = 2 Euclidean, r → ∞ Chebyshev (max coordinate difference). Scaling the features first matters whenever units differ.

ROC space plots TPR (vertical) against FPR (horizontal). A (0,1) is the perfect classifier — all positives detected with no false alarms; B (1,1) is the "always positive" rule; C (1,0.5) has FPR = 1 and detects only half the positives, so it is poor. (See also 2022 Part A Q10.)

Sick = positive class. TP = sick & tested positive = 620; FN = sick & tested negative = 380; FP = healthy & tested positive = 180; TN = healthy & tested negative = 8,820. Totals: 1,000 sick + 9,000 healthy = 10,000.

Q20

High bias / low variance + ROC space

14 marks

a) Interpret a model with high bias and low variance. b) State ROC space and curve; which points are perfect, always-positive and always-negative, and why?

Answer
a) High bias, low variance

This is the underfitting corner of the bias–variance trade-off.

  • High bias: the average prediction is systematically far from the true function — the model is too simple / too regularised, makes strong assumptions and misses informative structure (e.g. fitting a straight line to curved data).
  • Low variance: re-fitting on different training samples yields almost the same model — predictions are stable but consistently wrong.
  • Diagnostic signature: high training error and similarly high test error, with only a small train–test gap.
  • Fixes: add features or polynomial/interaction terms, increase model capacity, reduce regularisation, train longer, tune the optimiser, or reduce noise in the data. (The opposite failure, low bias + high variance / overfitting, needs regularisation, more data, bagging or early stopping.)
b) ROC space and curve

ROC space has FPR = FP/(FP+TN) on the horizontal axis and TPR = TP/(TP+FN) on the vertical axis, both in [0,1]. A ROC curve is traced by varying the classifier's decision threshold: at a low threshold more points are labelled positive (both TPR and FPR rise); at a high threshold fewer are (both fall). The diagonal is random guessing; the area under the curve (AUC) summarises overall quality; the convex hull gives optimal operating points.

(0, 1) perfect — TPR = 1 (all positives caught), FPR = 0 (no false alarms) (1, 1) always positive — everything labelled +: TP/(TP+FN)=1, FP/(FP+TN)=1 (0, 0) always negative — everything labelled −: TP = FP = 0, so TPR = FPR = 0 diagonal (0,0)→(1,1) — random guessing (AUC = 0.5); below it = worse than random

Why: these are the degenerate corners — a perfect classifier makes no errors; the always-positive rule makes every negative a false positive; the always-negative rule finds no positives and raises no false alarms. A useful classifier's curve bows toward the top-left corner (0,1), and a threshold is chosen at the point on that curve best matching the application's cost of false positives versus false negatives.

Exam tip (14 marks): For (a) define bias and variance, give the train/test-error signature and fixes. For (b) state both axis definitions, explain threshold sweeping, then give each special point with its coordinate reasoning.
