Short derivations

MLE of a Bernoulli p. L(p) = ∏p^{xᵢ}(1−p)^{1−xᵢ} → ℓ = k ln p + (n−k) ln(1−p); set dℓ/dp = k/p − (n−k)/(1−p) = 0 ⇒ p̂ = k/n (sample mean).
K-means centre = mean. Minimise J = Σ_{x∈C}‖x−μ‖²; set ∂J/∂μ = −2Σ(x−μ) = 0 ⇒ μ = (1/|C|)Σx.
PCA direction. Maximise vᵀSv with ‖v‖=1; Lagrange gives 2Sv − 2λv = 0 ⇒ Sv = λv, max variance = λ₁.
Information gain. Split S into Sᵥ: expected remaining entropy = Σᵥ(|Sᵥ|/|S|)H(Sᵥ); gain = H(S) − that. Pick the maximum.

Exam rules of thumb

Question says…Do this
"estimate parameter"Write likelihood → log → derivative = 0 → check second derivative
"first splitting attribute"Compute entropy(S) and information gain for EVERY attribute; pick maximum
"classify instance"Compute unnormalised posterior score per class; pick largest, then normalise if asked
"two rounds of K-means"Assign → recompute centres → assign again → report centres after round 2
"ROC points"(0,1) perfect, (1,1) always positive, (0,0) always negative
"bias high, variance low"Underfitting: too simple, large training error, similar test error → add features/complexity
"kernel function proof"Show symmetry and positive semi-definiteness (ΣcᵢcⱼKᵢⱼ = ‖Σcᵢφ(xᵢ)‖² ≥ 0)

Common mistakes

  • K-means: iterating to convergence when only two rounds were asked — report centres after round 2, not the final ones.
  • K-means: forgetting to recompute centres before the second assignment; using initial centres twice.
  • Dendrogram: giving only the merge heights without redrawing the reduced distance matrix at each step.
  • Linkage: using min where complete linkage needs max — single chains (1,2,3), complete is compact (1,3,6).
  • PCA: skipping standardisation, so a large-scale feature dominates the covariance matrix.
  • ROC: quoting accuracy instead of TPR/FPR, or mixing up (1,1) always-positive with (0,1) perfect.
  • AUC: claiming 0.5 is good — it is random guessing.
  • CV: tuning hyperparameters on the test folds (optimistic bias); use nested CV.
  • Bootstrap: sampling without replacement — OOB ≈ 36.8% requires sampling with replacement.
  • Bagging vs boosting: swapping their effects — bagging lowers variance, boosting lowers bias.
  • MLE: differentiating the likelihood instead of the log-likelihood, or forgetting the normalising constant in Bayes.
