ML Paradigms & Bayesian Formulation

Before any algorithm makes sense, you need the map: what kinds of learning exist, when each is used, and how probability — especially Bayes' theorem and parameter estimation — underpins the whole field. This page covers the four ML paradigms, semi-supervised learning, and the Bayesian way of thinking about learning from data under uncertainty.

Supervised Unsupervised Semi-supervised Reinforcement Bayes
01

What Is Machine Learning?

Definition

Machine learning is a branch of artificial intelligence that focuses on developing models and algorithms that let computers learn from data without being explicitly programmed for every task. In simple terms: ML teaches a system to think and understand like a human by learning patterns from examples, rather than following a fixed rule written by a person.

That is the core shift: traditional software says "if X then do Y"; machine learning says "here are many examples of X and the correct Y — figure out the rule yourself." The model is the learned rule, and it is trained on data, then used to make predictions or decisions on new, unseen data.

Key idea: the system improves with experience (data). The more representative the data, the better the model generalises to situations it has not seen before.
02

The Three Core Types of Machine Learning

Paradigms at a glance

SSupervised Learning

Trains models on labelled data to predict or classify new, unseen data. Each training example comes with the correct answer (the label), so the model learns a mapping from inputs to outputs.

Sub-types: Classification (predict discrete labels/categories) and Regression (predict continuous numerical values).

UUnsupervised Learning

Finds patterns or groups in unlabelled data — there is no "correct answer" provided. The model looks for structure on its own, such as clusters of similar items or ways to reduce many features to a smaller set.

Categories: Clustering, Association Rule Mining, Dimensionality Reduction.

RReinforcement Learning

Learns through trial and error to maximise a reward. An agent takes actions in an environment, receives feedback in the form of rewards or penalties, and gradually learns which actions lead to the best long-term outcome.

Ideal for decision-making tasks — e.g. game playing, robotics, resource scheduling — where there is no fixed labelled dataset, just interaction and feedback.

03

Unsupervised Learning — Three Categories

Structure without labels

CClustering

Groups similar data points together so that items in the same group (cluster) are more alike than items in other groups. There is no "correct" label — the grouping emerges from the data itself.

Example: grouping customers by purchasing behaviour, or grouping documents by topic. Common algorithms: k-means, hierarchical clustering, EM.

AAssociation Rule Mining

Discovers rules that describe how items tend to appear together in data. An association rule says "if X happens, Y tends to happen too" — useful for finding co-occurrence patterns.

Classic example: market-basket analysis — "customers who buy bread often also buy butter." Metrics: support, confidence, lift.

DDimensionality Reduction

Reduces the number of features (dimensions) in a dataset while trying to preserve the important information. High-dimensional data is hard to work with and often contains redundant or correlated features.

Helps with visualisation, speed, and avoiding overfitting. Example: Principal Component Analysis (PCA) — covered in detail in Module 4.

04

Reinforcement Learning — Learning by Reward

Interaction + feedback

Reinforcement learning (RL) is different from supervised and unsupervised learning because it learns from interaction. An agent acts in an environment, and after each action it receives a reward (or penalty) — a numerical signal that tells it how good that action was.

The agent's goal is not to maximise the immediate reward, but the cumulative reward over time. This makes RL suited to problems where a short-term sacrifice can lead to a better long-term outcome — exactly the kind of sequential decision-making that shows up in games, robotics, and control systems.

Contrast with supervised learning: in supervised learning you are given the correct answer for each example. In RL you are given a reward signal that tells you how well you did, but not necessarily the one best action. The agent must explore (try new actions) and exploit (use what it already knows works) to learn the best policy.

05

Semi-Supervised Learning

Between the two

Semi-supervised learning sits between supervised and unsupervised learning. It uses a mix of labelled and unlabelled data — typically a small amount of labelled data together with a much larger amount of unlabelled data.

This is useful precisely because labelling data is costly or limited. Getting labels often requires a human expert (e.g. a doctor labelling medical images, or someone transcribing speech), which is slow and expensive. Meanwhile, raw unlabelled data (images, text, sensor readings) is often abundant and cheap.

Why it matters: semi-supervised learning tries to get the benefit of labelled data (the supervision) while also exploiting the structure in the large unlabelled set (the unsupervised part) to improve the model. It is a practical answer to the real-world situation where labels are the bottleneck.
06

Bayesian Formulation — Thinking in Probabilities

Uncertainty

The Bayesian formulation is the probabilistic way of thinking about learning. Bayes' theorem explains how to update the probability of a hypothesis when new evidence is observed. In machine learning, the "hypothesis" is often the model or the model's parameters, and the "evidence" is the data we observe.

At its heart, Bayesian learning combines prior knowledge with observed data to make better decisions under uncertainty. Rather than producing a single fixed answer, it works with probabilities — how likely a hypothesis is, given what we knew before and what we have now seen.

What Bayesian formulation givesWhy it matters
Handles uncertainty and noisy data effectivelyReal data is rarely perfect; the Bayesian view quantifies rather than ignores uncertainty
Supports probabilistic interpretation of predictionsInstead of just "yes/no," the model can say how confident it is — essential for risk analysis and diagnosis
Enables learning even with limited dataBy bringing in a prior (what we believe before seeing the data), useful learning is possible even when data is scarce
Key role in risk analysis and diagnosisProbabilities are the natural language for "how likely is this diagnosis / failure / risk?"
Simple intuition: Bayes' theorem is the mathematics of "updating your belief." You start with a prior belief, see some evidence, and end with a posterior belief that combines both. In ML, this is the foundation for methods like Bayesian learning and the MAP estimate.
07

Mathematical Formulation of Bayes' Theorem

The formula

Bayes' theorem relates conditional probabilities. In the context of machine learning it is usually written as:

P(H | D) = P(D | H) · P(H) / P(D)

P(H | D)Posterior

The probability of the hypothesis H after observing the data D. This is what we want to compute — our updated belief after seeing the evidence.

P(D | H)Likelihood

The probability of observing the data D if the hypothesis H were true. It measures how well the hypothesis explains the data.

P(H)Prior

The probability of the hypothesis before seeing the data — our initial belief, based on prior knowledge or assumptions.

P(D)Evidence

The probability of the data overall. It acts as a normalising constant so the posterior sums to 1. In many ML settings it does not depend on the hypothesis and can be treated as a constant.

Reading it in words: the posterior (updated belief) is proportional to the likelihood (how well the hypothesis fits the data) times the prior (what we believed before). Bayes' theorem gives the exact way to combine them.
08

Connecting the Paradigms to Estimation

Why this matters for M2

The paradigms on this page are the what; parameter estimation (covered in the next module) is the how for the supervised and Bayesian parts. In particular:

  • Supervised learning needs a way to fit a model to labelled data — that is estimation: given data, find the parameters (weights, probabilities, tree splits) that best explain it.
  • Maximum Likelihood Estimation (MLE) asks: which parameter values make the observed data most probable? It is a core, general method for fitting models.
  • Maximum A Posteriori (MAP) extends MLE by including a prior — it is the Bayesian version, combining the data (likelihood) with prior belief (prior) to get the most probable parameters.
  • The Bayesian formulation is the bigger picture: learning as reasoning about probabilities of hypotheses and parameters given data.
Bridge to Module 2: the next module takes these ideas and works them out concretely — MLE for specific distributions (binomial, Poisson, exponential, normal), MAP with priors, and the point vs. interval estimation distinction. If the paradigms here feel abstract, the worked examples in Module 2 are where they become concrete.
09

MLE & MAP — Worked Example (Coin Toss)

From the handwritten notes / CO questions

MLE finds the parameter values that maximise the probability of the observed data. MAP additionally multiplies by a prior and maximises the posterior.

Posterior (Bayes)

P(θ | D) = P(D | θ) · P(θ) / P(D)

Estimators

θ̂MLE = arg maxθ P(D|θ)  ·  θ̂MAP = arg maxθ P(θ|D) = arg maxθ P(D|θ)·P(θ)

Worked — coin tossed 100 times, lands heads 62 times

Let θ = P(heads). The data likelihood is binomial: P(D|θ) = C(100,62)·θ⁶²(1−θ)³⁸.

Maximise w.r.t. θ → d/dθ [62·lnθ + 38·ln(1−θ)] = 0 → 62/θ = 38/(1−θ)

θ̂MLE = 62/100 = 0.62   (the observed frequency)

With a prior on θ (e.g. a Beta / normal), MAP pulls this estimate toward the prior mean — and as the number of tosses → ∞, MAP converges to the same value as MLE.
