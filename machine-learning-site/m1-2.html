MLE & MAP for Distributions

The core of parameter estimation: derive the Maximum Likelihood Estimator (MLE) for the common distributions you meet in ML — Bernoulli/binomial, Poisson, exponential, and Gaussian/normal — then see how MAP adds a prior. Each derivation follows the same recipe: write the likelihood, take the log, differentiate, set to zero.

MLE Poisson Exponential Gaussian
01

Setup & the Recipe

Method

Given i.i.d. samples x₁…xₙ from a distribution with parameter θ, the likelihood is the joint density viewed as a function of θ:

\(L(\theta)=P(D\mid\theta)=\prod_{i=1}^{n}p(x_i\mid\theta)\)

The MLE maximizes it; in practice we maximize the easier log-likelihood:

\(\ell(\theta)=\sum_i\ln p(x_i\mid\theta),\quad\hat{\theta}_{\text{MLE}}=\arg\max_{\theta}\ell(\theta)\)
Recipe (every derivation below): ① write p(x|θ); ② take ln; ③ differentiate w.r.t. θ; ④ set = 0; ⑤ solve. Derivatives of sums turn products into clean linear equations.
03

Poisson (count data)

Derivation

For counts with rate λ > 0, p(x|λ) = e−λ λx / x!. Log-likelihood:

\(\ell(\lambda)=\sum\bigl[-\lambda+x_i\ln\lambda-\ln(x_i!)\bigr]=-n\lambda+\bigl(\sum x_i\bigr)\ln\lambda+\text{const}\)

dℓ/dλ = −n + (Σxi)/λ = 0  ⟹  λ̂ = (1/n) Σ xi = x̄.

Worked: events per hour observed as 3, 5, 4, 6, 2 → x̄ = 20/5 = 4 → λ̂ = 4 events/hour.

04

Exponential (waiting times)

Derivation

For positive waiting times with rate λ > 0, p(x|λ) = λ e−λx. Log-likelihood:

\(\ell(\lambda)=n\ln\lambda-\lambda\sum x_i\)

dℓ/dλ = n/λ − Σxi = 0  ⟹  λ̂ = n / Σ xi = 1 / x̄.

Worked: mean waiting time x̄ = 5 min → λ̂ = 1/5 = 0.2 per minute. (Note: for exponential, the MLE of λ is the reciprocal of the sample mean — the opposite of Poisson.)

05

Gaussian / Normal (two parameters)

Derivation

For N(μ, σ²), p(x) = (1/√(2πσ²)) e−(x−μ)²/(2σ²). Log-likelihood (dropping constants):

\(\ell(\mu,\sigma^{2})=-\frac{n}{2}\ln\sigma^{2}-\frac{1}{2\sigma^{2}}\sum(x_i-\mu)^{2}\)

Differentiate w.r.t. μ, then w.r.t. σ²:

\(\frac{\partial\ell}{\partial\mu}=\frac{1}{\sigma^{2}}\sum(x_i-\mu)=0\;\Longrightarrow\;\hat{\mu}=\bar{x}=\frac{1}{n}\sum x_i\)
\(\frac{\partial\ell}{\partial\sigma^{2}}=-\frac{n}{2\sigma^{2}}+\frac{1}{2\sigma^{4}}\sum(x_i-\mu)^{2}=0\;\Longrightarrow\;\hat{\sigma}^{2}=\frac{1}{n}\sum(x_i-\bar{x})^{2}\)

Worked: samples 2, 4, 6, 8 → x̄ = 5; σ̂² = [(−3)²+(−1)²+1²+3²]/4 = 20/4 = 5. So the MLE is the sample mean and the sample variance (dividing by n).

MLE vs unbiased variance: the MLE uses 1/n (biased); the usual "unbiased" estimator uses 1/(n−1). The syllabus MLE result is the 1/n form — know both and which is which.
06

MAP — Adding a Prior

Contrast

MAP maximizes the posterior instead of just the likelihood:

\(\hat{\theta}_{\text{MAP}}=\arg\max_{\theta}\bigl[\ell(\theta)+\ln P(\theta)\bigr]\)

The prior P(θ) acts as a regularizer. With a Gaussian prior on μ, N(μ₀, τ²), the MAP mean becomes a shrinkage estimate:

\(\hat{\mu}_{\text{MAP}}=\frac{\sum x_i/\sigma^{2}+\mu_{0}/\tau^{2}}{n/\sigma^{2}+1/\tau^{2}}\)

As the prior tightens (τ²→0) μ̂→μ₀; as data grows (n→∞) μ̂→x̄ — the prior loses influence. This is exactly the role of regularization in regression (M2).

07

Bias of Estimators

Note

A good estimator should be consistent (converges to the truth as n→∞) and, ideally, unbiased. The MLE mean μ̂ = x̄ is unbiased: E[x̄] = μ. But the MLE variance σ̂² = (1/n)Σ(x−x̄)² is slightly biased — its expectation is (n−1)/n · σ², so it underestimates σ². The usual fix is the unbiased sample variance s² = (1/(n−1))Σ(x−x̄)². This is the only place MLE and the "textbook" variance differ; everything else (means, rates, λ) is unbiased. (Bias–variance of predictors is covered in M5.)
