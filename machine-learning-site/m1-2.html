Bayesian Estimation — MLE & MAP

The Bayesian way of learning parameters from data: treat the model as fixed and the parameters as unknown, then use the data to find the most likely parameters (MLE) or the most likely parameters given both data and prior belief (MAP). Includes worked parameter-estimation examples.

MLE MAP Posterior
01

From Bayes' Theorem to Estimation

Setup

Bayes' theorem relates the probability of a hypothesis (here, a parameter value θ) after seeing data D:

P(θ | D) = P(D | θ) · P(θ) / P(D)

where P(D) = ∫ P(D|θ)·P(θ) dθ is just a normalizing constant. Read it as:

  • Prior P(θ) — belief about θ before seeing data.
  • Likelihood P(D | θ) — how probable the observed data is under parameter θ.
  • Posterior P(θ | D) — updated belief after seeing data.
Big picture: ML "learns" by maximizing the likelihood (MLE) or the posterior (MAP). The prior is what separates MAP from MLE — it lets you inject domain knowledge ("θ is probably near 0.5").
02

Maximum Likelihood Estimation (MLE)

Method

MLE picks the θ that makes the observed data most probable, ignoring any prior:

θ̂MLE = argmaxθ P(D | θ)

In practice we maximize the log-likelihood (monotonic, turns products into sums):

θ̂MLE = argmaxθ Σi log P(xi | θ)

For independent, identically distributed data this is just "choose the parameter that best explains what you saw."

03

Worked Example — Coin Toss (Bernoulli MLE)

Worked

Suppose we toss a coin n = 100 times and observe h = 62 heads. Model the outcome as Bernoulli(θ), where θ is the probability of heads. The likelihood of the data is:

P(D | θ) = θh · (1 − θ)n − h = θ62 · (1 − θ)38

Log-likelihood: ℓ(θ) = 62·ln θ + 38·ln(1 − θ). Maximize by setting the derivative to zero:

dℓ/dθ = 62/θ − 38/(1 − θ) = 0 ⟹ 62(1 − θ) = 38θ ⟹ 62 = 100θ ⟹ θ̂ = 0.62
Result: the MLE is simply the observed frequency, θ̂ = h/n = 62/100 = 0.62. This is why MLE is intuitive: it is the empirical proportion.
04

Maximum A Posteriori (MAP)

Method

MAP also maximizes the posterior, which includes the prior:

θ̂MAP = argmaxθ P(D | θ) · P(θ)

or, in logs: argmaxθ [ Σi log P(xi | θ) + log P(θ) ].

The prior acts as a regularizer. A common choice is a Beta prior for Bernoulli data: P(θ) ∝ θα−1(1−θ)β−1. With a Beta(α,β) prior, the MAP estimate becomes:

θ̂MAP = (h + α − 1) / (n + α + β − 2)
Effect of the prior: with α = β = 1 (uniform prior) MAP equals MLE. With a stronger prior (e.g. α = β = 2, "biased toward fair"), the coin example gives θ̂ = (62+1)/(100+2) ≈ 0.618 — nudged slightly toward 0.5. The prior prevents over-confident estimates from small samples.

Posterior, MLE, MAP — When to Use Which

Summary
ApproachMaximizesUses prior?Best when
MLELikelihood P(D|θ)NoLarge dataset, no strong prior belief
MAPLikelihood × PriorYesSmall dataset, or you have domain knowledge
PosteriorFull P(θ|D)YesYou need uncertainty (e.g. confidence intervals)
