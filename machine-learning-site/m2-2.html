Naive Bayes & Decision Trees

Two foundational supervised classifiers. Naive Bayes applies Bayes' theorem with the "naive" assumption that features are independent. Decision trees split the data by asking the most informative question first (using entropy / information gain). Both come with full worked examples.

Bayes ID3 Entropy
01

Naive Bayes — the Idea

Classifier

For a class C and feature vector x = (x₁,…,xₙ), Bayes' theorem gives the posterior:

P(C | x) = P(x | C) · P(C) / P(x)

The naive assumption: features are conditionally independent given the class, so P(x|C) = Πi P(xi | C). The classifier picks the class with the largest posterior:

Ĉ = argmaxC [ P(C) · Πi P(xi | C) ]
Why "naive"? Real features are rarely independent, yet the method works surprisingly well — it is fast, needs little data, and is a strong baseline for text/spam classification.
02

Worked Example — Play Tennis

Worked

Training data (14 days): features Outlook, Temp, Humidity, Wind; label Play = Yes/No. Class priors:

P(Yes) = 9/14    P(No) = 5/14

Likelihoods from the table (counts / class total):

Feature=valueP(·|Yes)P(·|No)
Outlook=Sunny2/93/5
Outlook=Overcast4/90/5
Outlook=Rain3/92/5
Humidity=High3/94/5
Humidity=Normal6/91/5
Wind=Strong3/93/5
Wind=Weak6/92/5

Test 1: <Sunny, Cool, High, Strong>

P(Yes)·Π = (9/14)·(2/9)·P(Cool|Yes)·(3/9)·(3/9) ≈ 0.0053
P(No)·Π = (5/14)·(3/5)·P(Cool|No)·(4/5)·(3/5) ≈ 0.0206

Since 0.0206 > 0.0053 → predict No.

Test 2: <Overcast, Mild, Normal, Weak>

P(Yes)·Π = (9/14)·(4/9)·(6/9)·(6/9) ≈ 0.0278   (largest) → predict Yes.
Takeaway: multiply the prior by every matching feature-likelihood, then compare classes. Zero-likelihood features are handled with smoothing (Laplace) in practice.
03

Decision Trees & Entropy

ID3

A decision tree asks a feature question at each node to split the data. ID3 picks the question that most reduces entropy ( disorder ). Entropy of a set with class proportions pi:

H(S) = − Σi pi log2 pi

Worked: the 14 tennis examples have 9 Yes, 5 No:

H(S) = −(9/14)log₂(9/14) − (5/14)log₂(5/14) = 0.940 bits

Information gain of splitting on feature A:

Gain(S, A) = H(S) − Σv (|Sv|/|S|) · H(Sv)

The feature with the highest gain is chosen as the root, and the process repeats on each child. (For the tennis set the gains work out roughly: Outlook ≈ 0.24, Wind ≈ 0.48, Humidity ≈ 0.15, Temp ≈ 0.03 — so Wind then Humidity are the strongest splitters after Outlook.)

Overfitting: a tree grown to full depth memorizes the training data. Prune (pre- or post-) or limit depth to keep it general. C4.5 extends ID3 with continuous features and pruning.
