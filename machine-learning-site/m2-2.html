Naive Bayes & Decision Trees

Two foundational supervised classifiers. Naive Bayes applies Bayes' theorem with the "naive" assumption that features are independent. Decision trees split the data by asking the most informative question first (using entropy / information gain). Both come with full worked examples.

Bayes ID3 Entropy
01

Naive Bayes — the Idea

Classifier

For a class C and feature vector x = (x₁,…,xₙ), Bayes' theorem gives the posterior:

\[P(C\mid x) = \frac{P(x\mid C)\,P(C)}{P(x)}\]

The naive assumption: features are conditionally independent given the class, so P(x|C) = Πi P(xi | C). The classifier picks the class with the largest posterior:

\[\hat{C}=\arg\max_{C}\Bigl[P(C)\cdot\prod_i P(x_i\mid C)\Bigr]\]
Why "naive"? Real features are rarely independent, yet the method works surprisingly well — it is fast, needs little data, and is a strong baseline for text/spam classification.
03

Decision Trees & Entropy

ID3

A decision tree asks a feature question at each node to split the data. ID3 picks the question that most reduces entropy ( disorder / impurity ). Entropy of a set with class proportions pi:

\[H(S)=-\sum_i p_i\log_2 p_i\]

Information gain of splitting on feature A is the drop in impurity after the split — the parent entropy minus the weighted average entropy of the child branches:

\[\text{IG}(S,A)=H(S)-\sum_{v\in\text{Values}(A)}\frac{|S_v|}{|S|}\cdot H(S_v)\]
Formal definition (information gain): if after splitting on A the data partitions into branches v, with |Sv| instances taking branch v, the total impurity after the split is the weighted sum I′(S,A) = − Σv (|Sv| ⁄ |S|) Σi pi,v log2 pi,v (Alpaydın eq. 9.8). Information gain is then IG(S, A) = I(S) − I′(S, A): the split that gives the largest decrease in impurity is chosen. ID3, C4.5 and CART all select the split that minimizes this post-split impurity (equivalently, maximizes the gain).

Entropy is not the only impurity measure. For a two-class problem (p, 1−p), any nonnegative φ(p,1−p) that is maximal at p = ½ and zero at p = 0 or 1 works; the textbook lists three, with little practical difference between them:

Entropy:   \[\phi = -p\log_2 p - (1-p)\log_2(1-p)\]
Gini index:   \[\phi = 2p(1-p) \qquad\text{Gini index}\]    Misclassification error:   \[\phi = 1 - \max(p,1-p) \qquad\text{Misclassification error}\]

The feature with the highest gain is chosen as the root, and the process repeats on each child. (For the tennis set the gains work out roughly: Outlook ≈ 0.24, Wind ≈ 0.48, Humidity ≈ 0.15, Temp ≈ 0.03 — so Wind then Humidity are the strongest splitters after Outlook.)

Overfitting & pruning: a tree grown to full depth memorizes the training data, so it overfits when there is noise. Prepruning stops early — e.g. do not split a node reached by fewer than ~5% of the training set, or once its impurity falls below a threshold θI. Postpruning grows the full tree to zero training error, sets aside a separate pruning set, and replaces each subtree by a leaf if the leaf does no worse on the pruning set; postpruning is faster to state and generally yields more accurate trees than prepruning. C4.5 extends ID3 with continuous features and pruning.
