Perceptron, MLP, Backpropagation & Support Vector Machines

This module is the bridge from the simpler models of Module 2 to the powerful learners used in practice. On one side, neural networks — the perceptron, multilayer feedforward networks, activation functions (sigmoid, ReLU, tanh), and the backpropagation algorithm that trains them. On the other, support vector machines — the maximum-margin idea, the mathematics behind it, soft-margin classification, and the kernel trick that makes SVMs work on non-linear problems. Both are among the most examinable topics in the course.

01

The Perceptron

The simplest neural unit

The perceptron is the simplest kind of artificial neuron — a binary classifier that makes its decision by taking a weighted sum of its inputs and firing (output 1) or not (output 0) depending on whether that sum crosses a threshold. It is the historical starting point of neural-network research and the building block from which multilayer networks are made.

Structure

A perceptron has n inputs x₁ … xₙ, each with a weight w₁ … wₙ, a bias b, and an output. The net input is

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b

The output is a step (threshold) function of z:

y = 1 if z ≥ 0 , else y = 0

Intuition: each weight says how important its input is; the bias is a threshold adjuster. The perceptron fires when the weighted evidence for "1" is strong enough.

Decision boundary

Because the output is decided by w·x + b ≥ 0, the perceptron separates the input space with a linear boundary — a line (in 2-D), a plane (in 3-D), a hyperplane (in higher dimensions).

Key limitation: a single perceptron can only learn linearly separable problems. It cannot learn XOR, for example. This limitation is what motivated multilayer networks and, later, SVMs.

Perceptron Learning

The perceptron learns by correcting its mistakes. For each training example, if the perceptron's prediction is wrong, the weights are updated in the direction that would have made the correct prediction. The rule is simple and incremental — one pass over the data at a time, repeated until no mistakes remain (if the data is linearly separable).

wⱼ ← wⱼ + η · (target − output) · xⱼ    ,    b ← b + η · (target − output)

How to read the rule: if the target is 1 and the perceptron output 0 (missed a positive), the error (target − output) is +1, so each weight moves toward the input values — making it more likely to fire next time. If the target is 0 and output is 1 (false alarm), the error is −1, so weights move away from the inputs — making it less likely to fire. The learning rate η controls the step size.
A worked perceptron step: suppose a perceptron has weights w₁=0.5, w₂=−0.3, bias b=0.1, and inputs x₁=1, x₂=1. Then z = 0.5·1 + (−0.3)·1 + 0.1 = 0.3. Since z ≥ 0, the output is 1. If the target was 0 (a mistake), the error is 0 − 1 = −1. With η=0.1, the new weights are w₁ = 0.5 + 0.1·(−1)·1 = 0.4, w₂ = −0.3 + 0.1·(−1)·1 = −0.4, b = 0.1 + 0.1·(−1) = 0.0. The perceptron is now less likely to fire on (1,1).

Worked — forward pass (from the handwritten notes)

Inputs x₁=1, x₂=3 with weights w₁=0.3, w₂=0.1; output neuron uses a binary step activation.

y_in = 1·0.3 + 3·0.1 = 0.5

y = step(0.5) = 1   (since 0.5 ≥ 0)

02

Multilayer Feedforward Network

Stacking neurons

A multilayer feedforward network (also called a multilayer perceptron, MLP) is a network of perceptrons arranged in layers: an input layer, one or more hidden layers, and an output layer. Information flows forward — from input, through the hidden layers, to the output. Unlike a single perceptron, a multilayer network can learn non-linear decision boundaries, because the hidden layers combine several linear splits.

Architecture

Each neuron in a hidden or output layer receives inputs from all neurons in the previous layer. A network with L layers has weights connecting each layer to the next. The first layer holds the raw inputs; the last layer produces the output (one neuron per class for classification, one or more for regression).

Why "feedforward": there are no cycles — connections go only forward from one layer to the next. This is what makes backpropagation (the training algorithm) a clean, layer-by-layer computation.

Universal approximation

A network with at least one hidden layer and a non-linear activation can approximate any continuous function to arbitrary accuracy, given enough hidden neurons. This is the theoretical reason multilayer networks are so powerful — they are not limited to linear boundaries the way a single perceptron is.

The catch: "enough hidden neurons" can be a lot, and training such a network is non-trivial — which is where backpropagation comes in.
A simple 3-layer network: 2 inputs → 4 hidden neurons → 1 output neuron. Each hidden neuron computes a weighted sum of the 2 inputs plus bias, applies an activation, and passes the result to the output neuron. The output neuron does the same with the 4 hidden outputs. The network has 2×4 + 4 = 12 weights plus 4+1 = 5 biases. Training adjusts all 17 numbers to minimise error.

A 2-input, 4-hidden-neuron, 1-output feedforward network. Every neuron in one layer connects to every neuron in the next (fully connected).

03

Activation Functions

What makes a network non-linear

Each neuron in a multilayer network applies an activation function to its weighted sum z before passing the result on. Without a non-linear activation, a multilayer network would collapse into a single linear transformation — no matter how many layers, the whole thing would be equivalent to one linear model. The activation function is what introduces the non-linearity that gives the network its power.

ActivationFormulaOutput rangeShape / key property
Sigmoid (logistic)f(z) = 1 / (1 + e−z)(0, 1)S-shaped, smooth, bounded. Historically common; saturates at large |z| (gradients vanish).
Tanhf(z) = (ez − e−z) / (ez + e−z)(−1, 1)S-shaped like sigmoid but zero-centred — outputs have mean ≈ 0, which helps the next layer learn.
ReLU (Rectified Linear Unit)f(z) = max(0, z)[0, ∞)Linear for z>0, zero for z≤0. Simple, fast, no saturation for positive z — currently the most used.

Sigmoid (red, 0→1), tanh (blue, −1→1, zero-centred), ReLU (green, 0 for z<0, then linear). The dashed line marks z=0.

Sigmoid

Smooth and differentiable everywhere — nice for gradient-based learning. But it saturates: for large positive z it approaches 1, for large negative z it approaches 0, and in both cases the gradient is near zero. This vanishing gradient slows learning deep in a network.

Tanh

Like sigmoid but zero-centred (mean of outputs near 0), so the 다음 layer receives inputs centred around zero — this tends to make optimisation easier than with sigmoid, whose outputs are all positive. Still saturates at the extremes.

ReLU

The most popular activation today. For z > 0 it is just the identity (f(z)=z), so the gradient is 1 — no vanishing gradient for positive signals. It is sparse (many neurons output exactly 0), and very cheap to compute.

ReLU — the downside

A "dead ReLU" is a neuron that, due to its weights, always receives z ≤ 0 — it outputs 0 forever and never updates (gradient is 0 on the negative side). Also, ReLU is not smooth at z=0 (the derivative jumps), though in practice this rarely matters.

One way tanh is easier than logistic (CO3-Q4): tanh outputs are centred around zero (range −1 to +1), so the inputs to the next layer have mean near zero. Logistic outputs are all positive (range 0 to 1), so they push the next layer's weighted sums consistently positive or negative — this can create zig-zag gradient updates and slow convergence. The zero-centred property of tanh is one concrete reason it can train a bit faster than sigmoid in some networks.
ReLU advantage vs tanh (CO3-Q5a): for z > 0, ReLU's gradient is exactly 1 — it never vanishes for positive signals, so deep networks with ReLU tend to train much faster than with saturating activations like tanh. ReLU is also sparse and computationally cheaper. ReLU disadvantage vs tanh (CO3-Q5b): a dead ReLU (a neuron stuck outputting 0 because its weighted input is always ≤ 0) stops learning entirely, whereas tanh's smooth, everywhere-nonzero gradient means neurons keep updating — and tanh is bounded and smooth, which can be stabilising.
04

Backpropagation

How a network learns

Backpropagation (short for "backward propagation of errors") is the algorithm that trains a multilayer network. The idea is simple in principle: compare the network's output to the true answer, measure the error, and then propagate that error backward through the layers to figure out how much each weight contributed to the mistake — and adjust the weights to reduce it.

The basic idea (CO3, Part B Q16a — 10 marks): backpropagation is gradient descent applied to a network, where the gradient of the error with respect to each weight is computed efficiently by the chain rule of calculus, working backward from the output layer to the input layer. For each weight, we compute how the total error changes if we nudge that weight — and step the weight in the opposite direction. The "backward" part is the chain-rule pass: the error at a neuron is the weighted sum of the errors at the neurons it feeds into, multiplied by the derivative of its activation.

The algorithm in words

  1. Forward pass: feed an input through the network, layer by layer, to get the output prediction.
  2. Compute the error: compare the output to the true target using a loss function (e.g. squared error for regression, cross-entropy for classification).
  3. Backward pass (chain rule): starting at the output, compute the gradient of the error with respect to each neuron's output, then with respect to each weight and bias, moving backward layer by layer. Each neuron's "error signal" is the weighted sum of the error signals of the neurons it connects to, times its own activation derivative.
  4. Update weights: adjust every weight and bias by a small step opposite to its gradient (learning rate η).
  5. Repeat for each training example (or batch), over many epochs, until the error is small enough.
Why it works: the chain rule lets us reuse computations. The gradient for a weight in an early layer depends on the gradients of all the later layers — backpropagation computes all of these in one backward sweep, rather than estimating each gradient separately. That is what makes training a network with thousands or millions of weights feasible.

Illustrative example — a tiny network

Consider a network with 1 input x, 1 hidden neuron h, and 1 output y. Weights: input→hidden = w₁, hidden→output = w₂; biases b₁, b₂; activation f (say sigmoid) at the hidden neuron, and identity at the output. Given a training input x and target t:

h = f(w₁x + b₁)   ,   y = w₂h + b₂   ,   error E = ½(y − t)²

The backpropagation steps compute:

∂E/∂y = (y − t)  →  ∂E/∂w₂ = (y−t)·h  →  ∂E/∂b₂ = (y−t)

∂E/∂h = (y−t)·w₂  →  ∂E/∂z₁ = (y−t)·w₂·f′(z₁)  →  ∂E/∂w₁ = (y−t)·w₂·f′(z₁)·x

Reading this: the error signal (y−t) starts at the output. It flows back through w₂ to the hidden neuron (giving ∂E/∂h), is scaled by the hidden neuron's activation derivative f′(z₁) (the chain rule), and then flows back through x to the input weight w₁. Each weight's gradient is the error signal at the neuron it feeds, times the input that weight multiplies. The weights are then updated: w₁ ← w₁ − η·∂E/∂w₁, and similarly for the others.
Worked numbers: let x=1, t=1, w₁=0.5, b₁=0, w₂=0.8, b₂=0, sigmoid activation. Then z₁=0.5, h=f(0.5)=1/(1+e^{−0.5})≈0.622, y=w₂·h=0.8·0.622≈0.498. Error E=½(0.498−1)²≈0.126. ∂E/∂y=0.498−1=−0.502. ∂E/∂w₂=(−0.502)·0.622≈−0.312. ∂E/∂h=(−0.502)·0.8=−0.402. f′(z₁)=h(1−h)=0.622·0.378≈0.235. ∂E/∂w₁=(−0.402)·0.235·1≈−0.094. With η=0.1: new w₂=0.8−0.1·(−0.312)=0.831, new w₁=0.5−0.1·(−0.094)=0.509. The weights moved to reduce the error.

Support Vector Machines — Introduction

The maximum-margin idea

A Support Vector Machine (SVM) is a powerful classifier that works on a simple but deep principle: among all the lines (or planes, hyperplanes) that separate two classes, pick the one that leaves the widest possible gap — the maximum margin — between the classes. The points that sit right on the edge of that gap are the support vectors; they are the only points that matter for defining the boundary.

Maximum margin

Imagine two clouds of points, one labelled +1, one labelled −1, separated by a gap. A line right down the middle of the gap is the maximum-margin hyperplane. The margin is the perpendicular distance from the hyperplane to the nearest point of either class. Maximising this margin gives the classifier the best chance of handling new, unseen points correctly.

Why maximise the margin: a wider margin means the boundary is farther from the data points, so small errors or noise in new data are less likely to flip the prediction. It is a formal way of preferring a simple, robust separator over one that threads the needle between the points.

Support vectors

The support vectors are the training points that lie on (or inside, for soft margin) the margin boundaries. They are the "critical" points — if you removed any other point, the max-margin hyperplane would not change. The whole classifier is built from (and named after) these few support vectors.

Three properties of the SVM solution (CO3-Q1): (1) sparsity — the solution depends only on the support vectors, not on the other training points; (2) maximum margin — the hyperplane is the one that maximises the margin; (3) the solution is the unique maximum-margin separator for a given kernel and soft-margin parameter (under the standard convex formulation).

The solid green line is the maximum-margin hyperplane; the dashed lines are the margin boundaries. The circled points on the margin are the support vectors — the only points the boundary depends on.

The Mathematics — Maximum Margin Classification

The optimisation problem

The SVM is not just a good idea — it is a clean mathematical optimisation. We want the hyperplane w·x + b = 0 that separates the classes with the largest possible margin. The margin turns out to be 2 / ||w||, so maximising the margin is the same as minimising ||w|| (or, more conveniently, ½||w||²). The constraint is that every point must be on the correct side of the margin.

The constraints: for each training point xᵢ with label yᵢ ∈ {+1, −1}, we require yᵢ(w·xᵢ + b) ≥ 1. This says: the signed distance from the point to the hyperplane, times the label, is at least 1. Points with y=+1 must satisfy w·x+b ≥ 1; points with y=−1 must satisfy w·x+b ≤ −1. The points that satisfy this with equality (yᵢ(w·xᵢ+b) = 1) are exactly the support vectors on the margin.
Primal (hard-margin) optimisation:

minimise   ½ ||w||²

subject to   yᵢ (w·xᵢ + b) ≥ 1   ,   for all i

Reading it: we search over all possible (w, b) for the one that makes ½||w||² as small as possible while satisfying every point's margin constraint. Small ||w|| means a wide margin (margin = 2/||w||). This is a convex quadratic-programming problem — it has a unique global minimum (for a given separable dataset), and the solution is the maximum-margin hyperplane.
From primal to dual (the key step for kernels): introducing Lagrange multipliers αᵢ ≥ 0 for each constraint and applying the Karush-Kuhn-Tucker conditions leads to the dual problem — an equivalent optimisation that involves only the pairwise dot products of the training points:

maximise   Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ (xᵢ·xⱼ)

subject to   0 ≤ αᵢ ≤ C   (soft margin)   ,   Σᵢ αᵢ yᵢ = 0

Why this matters: in the dual, the training points only ever appear as dot products xᵢ·xⱼ. That is the door that opens to the kernel trick — if we can compute dot products in some (possibly very high-dimensional) feature space without ever constructing the features, we can plug them straight into the dual and get a maximum-margin classifier in that feature space. The αᵢ that are non-zero at the solution are the support vectors.
Recovering the hyperplane: once we have the αᵢ, the weight vector is w = Σᵢ αᵢ yᵢ xᵢ (a weighted combination of the support vectors only — the αᵢ for non-support vectors are zero). The decision for a new point x is: sign( Σᵢ αᵢ yᵢ (xᵢ·x) + b ). The bias b is recovered from any support vector on the margin.
Soft margin — the C parameter: the hard-margin formulation only works when the data is perfectly separable. Real data is not. The soft-margin SVM relaxes the constraint by allowing some points to violate the margin, controlled by slack variables ξᵢ ≥ 0 and a penalty parameter C:

minimise   ½ ||w||² + C · Σᵢ ξᵢ

subject to   yᵢ (w·xᵢ + b) ≥ 1 − ξᵢ   ,   ξᵢ ≥ 0

What C does: C is the trade-off between a wide margin and making fewer classification errors. Large C heavily penalises margin violations — the model tries hard to classify every training point correctly, risking a narrow margin and overfitting. Small C is more tolerant of violations — it prefers a wider margin, which can generalise better but may allow some training errors. Choosing C (usually by cross-validation) is a central part of using an SVM in practice.

Non-Linear SVM & Kernels

The kernel trick

A linear SVM can only draw a straight line (or plane). But most real problems are not linearly separable — the classes are tangled. The kernel trick lets an SVM draw a non-linear boundary without ever leaving the comfortable world of dot products: we map the data into a higher-dimensional feature space where it becomes linearly separable, and run a linear SVM there — but we do it implicitly, through a kernel function, never constructing the high-dimensional features.

The kernel trick (CO3-Q2 — why use a kernel instead of projecting directly?): to use a feature space, you would normally have to compute the mapping φ(x) for every point and then take dot products φ(xᵢ)·φ(xⱼ). But the feature space can be very high-dimensional — even infinite-dimensional (as with the RBF kernel). Explicitly constructing and storing φ(x) is impossible or absurdly expensive. A kernel function K(xᵢ, xⱼ) computes φ(xᵢ)·φ(xⱼ) directly from the original inputs, without ever finding φ. The dual SVM only needs these dot products, so we can replace every xᵢ·xⱼ with K(xᵢ, xⱼ) and the whole algorithm runs in the feature space for free.
How to extend an SVM to use kernels (CO3-Q3): take the dual formulation — in which the inputs appear only as dot products xᵢ·xⱼ — and replace every dot product with K(xᵢ, xⱼ). The optimisation is identical in form; only the "similarity" between points has changed. The decision function becomes sign( Σᵢ αᵢ yᵢ K(xᵢ, x) + b ). You have now trained a maximum-margin classifier in the (implicit) feature space of K, without ever constructing that space.
KernelFormulaFeature-space ideaWhen it fits
LinearK(x, y) = x·yNo mapping — stays in original spaceData is (roughly) linearly separable; fast, interpretable
PolynomialK(x, y) = (x·y + 1)dAll monomials up to degree d — interactions between featuresModerately non-linear problems; d is the polynomial degree
RBF (Radial Basis Function / Gaussian)K(x, y) = exp( −||x − y||² / (2σ²) )Infinite-dimensional feature space — very flexibleDefault choice for many problems; captures local, complex boundaries; σ (or γ = 1/(2σ²)) controls the "reach" of each support vector
Illustrating the Gaussian kernel (CO3-Q3 second part): with K(x,y) = exp(−||x−y||²), points that are close together in input space have K ≈ 1 (very similar in feature space); points far apart have K ≈ 0. The feature space is infinite-dimensional, and the decision boundary in the original space is a smooth, non-linear curve — the SVM can carve out arbitrarily complex regions, built from the "bumps" of the RBF kernels centred on the support vectors.
Worked kernel mapping — Q15(a): for a 2-D input and the polynomial kernel K(x,y) = (x·y + 1)², expand: (x·y + 1)² = (x₁y₁ + x₂y₂ + 1)² = x₁²y₁² + x₂²y₂² + 1 + 2x₁x₂y₁y₂ + 2x₁y₁ + 2x₂y₂. This is exactly the dot product of a 6-dimensional feature vector φ(x) = (x₁², x₂², 1, √2x₁x₂, √2x₁, √2x₂) with φ(y). So the kernel corresponds to an explicit mapping into a feature space of dimension 6 (the constant 1 plus 5 non-constant components; some treatments describe it as 5-D when the constant is treated as the bias term rather than a feature). Either way, the point is that a simple quadratic kernel lifts 2-D data into a much richer space where a linear separator can capture non-linear structure in the original input.
