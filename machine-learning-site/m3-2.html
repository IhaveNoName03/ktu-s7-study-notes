Module 3 · Part 2

Support Vector Machines

SVMs find the maximum-margin hyperplane that separates two classes with the widest possible gap. Points closest to the boundary are the support vectors. With kernels, the same idea draws non-linear boundaries in a high-dimensional feature space. Includes the primal/dual forms and a worked kernel example.

Margin Kernel Dual
01

Maximum-Margin Hyperplane

Primal

For linearly separable data, the decision boundary is a hyperplane w·x + b = 0. The margin is the distance from the boundary to the nearest point; SVM maximizes it. In the hard-margin case:

\(\text{minimize}\ \tfrac{1}{2}\,\lVert w\rVert^{2}\ \text{subject to}\ y_i(w\cdot x_i+b)\ge 1\ \forall i\)   subject to   yi(w·xi + b) ≥ 1   ∀i

Minimizing ½‖w‖² maximizes the margin (margin = 2/‖w‖). The constraints force every point to be at least 1 unit from the boundary in scaled space.

Support vectors: only the points that sit exactly on the margin (the active constraints) matter. Move any other point and the boundary doesn't change — that is why SVMs are memory-efficient at test time.
02

Soft Margin & the Dual

Real data

Real data isn't perfectly separable, so we allow small violations ξi (slack) and trade them off against margin width with a penalty C:

\(\text{minimize}\ \tfrac{1}{2}\lVert w\rVert^{2}+C\sum_i\xi_i\ \text{s.t.}\ y_i(w\cdot x_i+b)\ge 1-\xi_i,\ \xi_i\ge 0\)

The dual form (via Lagrange multipliers αi) reveals the kernel trick:

\(\text{maximize}\ \sum_i\alpha_i-\tfrac{1}{2}\sum_i\sum_j\alpha_i\alpha_j y_i y_j\,K(x_i,x_j)\ \text{s.t.}\ 0\le\alpha_i\le C,\ \sum_i\alpha_i y_i=0\)

The classifier becomes f(x) = sign( ΣSV αi yi K(xi, x) + b ).

C controls bias–variance: large C → few violations, narrow margin, risk of overfitting; small C → wider margin, more tolerance, smoother boundary.
03

Kernels — Non-Linear Boundaries

Key idea

A kernel K(x, x′) = φ(x)·φ(x′) computes the dot product in a lifted feature space without ever forming φ explicitly. Common kernels:

KernelFormulaUse
LinearK(x,x′) = x·x′Already linear / high-dim sparse
Polynomial(x·x′ + c)dNon-linear, bounded degree
RBF / Gaussianexp(−γ‖x−x′‖²)General non-linear (most used)
Sigmoidtanh(κ x·x′ + c)NN-like boundary
Kernel trick: map data to a space where classes are separable, then run the linear SVM there — all through K(·,·). RBF can separate arbitrarily curved boundaries given enough support vectors.
