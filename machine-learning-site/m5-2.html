Ensembles, Cross-Validation & Bias–Variance

How to make a good classifier great: combine many weak models (ensembles), estimate performance honestly with cross-validation, and understand the bias–variance trade-off that limits every model. Ends with the face-detection case study.

Bagging Boosting k-fold CV
01

Bias–Variance Decomposition

Theory

The expected test error splits into three parts:

\[\text{Error} = \text{Bias}^{2} + \text{Variance} + \text{Irreducible noise}\]
  • Bias — error from a too-simple model (underfitting); it consistently misses the pattern.
  • Variance — error from a too-sensitive model (overfitting); it changes a lot with small data changes.
The trade-off: as model complexity rises, bias falls but variance grows. The sweet spot minimizes their sum. Regularization and more data both help push the frontier.
02

Cross-Validation

Honest estimate

k-fold CV: split data into k equal parts; train on k−1, test on the held-out part; repeat k times and average the scores. Common choices: k = 5 or 10.

\[\text{CV score}=\frac{1}{k}\sum_{j=1}^{k}\text{error on fold }j\]

This uses all data for both train and test (just never at the same time), giving a stable estimate of how the model will perform on unseen data. Bootstrapping is the cousin that resamples with replacement to build confidence intervals.

Why not just use the training accuracy? a model can score 100% on data it already saw and fail on new data. CV measures generalization, not memorization.
03

Ensemble Methods

Combine
MethodHowIntuition
Bagging (e.g. Random Forest)Train many models on bootstrap samples, average/voteReduces variance
Boosting (e.g. AdaBoost, XGBoost)Train sequentially; each fixes the previous errorsReduces bias
StackingMeta-model learns to combine base models' outputsBest of both
Why ensembles win: independent models make different errors; averaging cancels many of them out. A Random Forest (many deep trees) is far more stable than one deep tree, which is why it is a default go-to.
04

Case Study — Face-Detection Classifier

Apply

Build a classifier that labels an image window "face / not-face":

  1. Features: pixel windows → Haar-like or HOG features (high-dimensional).
  2. Model: train a classifier (e.g. boosted decision stumps, as in Viola–Jones) on labelled windows.
  3. Assess: use ROC/AUC (m5-1) and k-fold CV to pick the threshold that meets the false-positive budget.
  4. Improve: an ensemble (boosting) lifts accuracy far above a single weak classifier.

This ties the whole course together: features + supervised learning + evaluation (ROC) + ensembles + honest CV.
