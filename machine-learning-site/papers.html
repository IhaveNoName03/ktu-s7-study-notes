Course Outcome 1 (CO1) — Estimation & MLE/MAP

4 questions
CO1 · Q13 marks
A coin is tossed 100 times and lands heads 62 times. What is the maximum likelihood estimate for θ, the probability of heads?
Answer: Bernoulli likelihood L(θ) = θ^62 (1−θ)^38. Log-likelihood ℓ = 62 ln θ + 38 ln(1−θ). dℓ/dθ = 62/θ − 38/(1−θ) = 0 → 62(1−θ) = 38θ → 62 = 100θ → θ̂ = 62/100 = 0.62. The MLE is simply the observed proportion of heads.
CO1 · Q23 marks
Suppose data x₁,…,xₙ are i.i.d. drawn from an exponential distribution exp(λ). Find the maximum likelihood for λ.
Answer: Exponential density f(x;λ) = λ e^{−λx}. Likelihood L(λ) = λⁿ e^{−λ Σxᵢ}. Log-likelihood ℓ = n ln λ − λ Σxᵢ. dℓ/dλ = n/λ − Σxᵢ = 0 → λ̂ = n / Σxᵢ = 1 / x̄. The MLE is the reciprocal of the sample mean.
CO1 · Q33 marks
Suppose x₁,…,xₙ are i.i.d. samples from a distribution with density f(x;θ) = (θ+1) x^θ for 0 ≤ x ≤ 1. Find the MLE for θ.
Answer: L(θ) = Π (θ+1) xᵢ^θ = (θ+1)ⁿ Π xᵢ^θ. ℓ = n ln(θ+1) + θ Σ ln xᵢ. dℓ/dθ = n/(θ+1) + Σ ln xᵢ = 0. Since ln xᵢ ≤ 0, let S = Σ ln xᵢ (negative). Then n/(θ+1) = −S → θ̂ = −n/S − 1 = −n/Σ ln xᵢ − 1.
CO1 · Q45 marks
Find the MLE and MAP estimator for the mean of a univariate normal distribution (known variance σ², unknown mean µ), with a normal prior mean ν, variance β². What happens as N → ∞?
Answer: Data xᵢ ~ N(µ, σ²), prior µ ~ N(ν, β²).
MLE: µ̂_MLE = x̄ (sample mean).
MAP: maximise log-likelihood + log-prior: −½σ²Σ(xᵢ−µ)² − ½β²(µ−ν)². Differentiating: Σ(xᵢ−µ)/σ² − (µ−ν)/β² = 0 → µ̂_MAP = (σ⁻² N x̄ + β⁻² ν) / (σ⁻² N + β⁻²) = a weighted average of the data mean and the prior mean.
As N→∞: the data term dominates the prior term (σ⁻²N grows), so µ̂_MAP → x̄ = µ̂_MLE. With enough data, the prior stops mattering and MAP converges to MLE. This is the classic "frequentist limit" of Bayesian estimation.

Course Outcome 2 (CO2) — Regression & Naive Bayes

2 questions
CO2 · Q13 marks
Linear regression on N points, D attributes, D ≈ 100. Would you prefer the closed-form solution or gradient descent?
Answer: Closed form needs (XᵀX)⁻¹ — a D×D matrix. With D≈100 that is 100×100 (cheap, 10⁴ entries). The cost is O(D³) ≈ 10⁶ — trivial. With "all D attributes linearly independent" and only N data points, if N is comparable to or smaller than D, (XᵀX) is invertible only if N≥D. Prefer closed form here (D=100 is tiny; gradient descent's advantage appears when D is huge, e.g. millions of features, or data doesn't fit in memory).
CO2 · Q23 marks
Three-class problem, labels y ∈ {0,1,2}, 3 binary attributes X₁,X₂,X₃ ∈ {0,1}. How many probability parameters are needed for Naive Bayes?
Answer: Naive Bayes: P(y) for each class + P(Xⱼ | y) for each attribute per class. P(y): 3 classes but sum to 1 → 2 free params. Each attribute given a class: 2 values → 1 free param per (attribute, class). 3 attributes × 3 classes = 9, but each conditional sums to 1 → 9 − 3 = 6. Total = 2 + 6 = 8 parameters. (Plus the class prior is the 2.) So 8 probability numbers fully specify the classifier.

Course Outcome 3 (CO3) — SVM & Neural Nets

5 questions
CO3 · Q13 marks
What are support vectors and list any three properties of the support vector classifier solution?
Answer: Support vectors are the training points that lie on (or inside, for soft margin) the margin boundaries — the critical points the hyperplane depends on. Three properties: (1) Sparsity — the solution depends only on support vectors, not on other points; (2) Maximum margin — it is the hyperplane that maximises the margin; (3) the solution is the unique maximum-margin separator for a given kernel / C (under the standard convex formulation).
CO3 · Q23 marks
Why use kernels to model a projection into feature space instead of projecting the dataset directly?
Answer: The feature space can be infinite-dimensional (e.g. the RBF kernel). Explicitly mapping every point and computing dot products there would be impossible / infinitely expensive. The kernel trick avoids it: the algorithm only ever needs dot products between points, and a kernel K(x,y) computes that dot product in feature space implicitly, without ever constructing the features. You get the power of an infinite-dimensional space at the cost of evaluating a simple function.
CO3 · Q35 marks
Describe how SVMs use kernels. Illustrate with the Gaussian kernel K(x,y) = e^{−(x−y)²}.
Answer: An SVM finds the maximum-margin hyperplane in the (possibly mapped) feature space. With kernels, instead of mapping x→φ(x) and computing φ(x)·φ(y), we replace the dot product with K(x,y). The dual optimum and the decision function sign(Σ αᵢ yᵢ K(xᵢ,x) + b) use only K.
Gaussian / RBF kernel K(x,y)=exp(−||x−y||²): points close in input space have K≈1 (very similar in feature space); points far apart have K≈0. The feature space is infinite-dimensional and very flexible — the decision boundary in the original space becomes a smooth, non-linear curve built from RBF "bumps" centred on the support vectors. σ (or γ=1/2σ²) controls the reach of each bump.
CO3 · Q43 marks
Briefly explain one way in which using tanh instead of logistic activations makes optimisation easier.
Answer: tanh is zero-centred (outputs range −1 to +1, mean ~0), whereas logistic sigmoid is always positive (mean ~0.5). With all-positive activations, gradients flowing back to the weights all have the same sign, so weight updates zig-zag in a narrow direction. Zero-centred outputs let gradients take both signs, which makes the updates more balanced and converges faster. (Batch normalisation later solved the same problem more generally.)
CO3 · Q55 marks
ReLU is most used instead of tanh. Draw both activation functions and give (a) an advantage, (b) a disadvantage of ReLU vs tanh.
Answer: tanh: S-shaped, −1 to +1. ReLU: f(x)=max(0,x) — flat at 0 for x<0, linear for x≥0.
(a) Advantage: ReLU is non-saturating for positive inputs, so gradients don't vanish on the positive side — training is faster and deep networks train more reliably. It is also cheap to compute (no exp). The sparsity (many zeros) can be regularising.
(b) Disadvantage: the "dying ReLU" problem — if a neuron's weights push all inputs negative, it outputs 0 forever and its gradient is 0, so it stops learning (dead neuron). tanh doesn't have this hard dead zone (though it can still saturate).

Course Outcome 4 (CO4) — Clustering

4 questions
CO4 · Q13 marks
Which similarity measure could compare feature vectors of two images? Justify.
Answer: Cosine similarity (dot product of the two vectors divided by their magnitudes) is a strong choice for image feature vectors. Image features (e.g. bag-of-visual-words, CNN embeddings) are often high-dimensional and the direction of the vector matters more than its magnitude (brightness/scale differences shouldn't dominate). Cosine ignores magnitude and compares orientation, so two images of the same scene at different exposures score high. Euclidean distance is an alternative when absolute pixel differences matter.
CO4 · Q23 marks
Illustrate the strength and weakness of the k-means algorithm.
Answer: Strengths: simple, fast (linear in N, D, k, iterations), scales to large datasets, easy to interpret (centroids are prototypes).
Weaknesses: must choose k in advance; sensitive to initial centres (can settle in a local optimum — hence k-means++ initialisation); assumes spherical, similarly-sized, equal-variance clusters (fails on elongated or varying-density clusters); sensitive to outliers; only works for Euclidean-ish distances; every point forced into one cluster (no "noise" class).
CO4 · Q310 marks
Apply k-means (Manhattan distance, k=3) to the eight given points with initial clusters C1={x1,x2,x3}, C2={x4,x5,x6}, C3={x7,x8}, until convergence.
Answer (method): The exact coordinates were given as a figure in the paper; the procedure is: (1) compute each cluster centroid as the Manhattan-median of its members (with Manhattan distance, the medoid/median minimises within-cluster cost); (2) reassign every point to the nearest centroid by Manhattan distance |Δx|+|Δy|; (3) repeat until no point changes cluster. Because the points and initial assignment are in the figure, carry out the iterations step by step — usually 2–4 iterations converge. State the final centroid coordinates and the final cluster membership. (The second given instance, A1…A8 with explicit coordinates, is worked the same way and is easier to compute by hand since the points are numeric.)

Course Outcome 5 (CO5) — Ensemble & Evaluation

5 questions
CO5 · Q13 marks
What is ensemble learning? Can an ensemble of linear classifiers learn a linearly non-separable set?
Answer: Ensemble learning combines multiple base models ("weak learners") into one stronger model — the idea that many modest models beat a single complex one (wisdom of crowds, reduced variance/bias). Yes — an ensemble of linear classifiers (e.g. boosted linear models, or averaging several linear separators) can represent a non-linear, non-separable decision boundary. Example: a majority vote of several lines can carve out a region that no single line can. (This is why boosted stumps — depth-1 trees — can learn any boundary.)
CO5 · Q23 marks
Describe boosting. What is its relation to ensemble learning?
Answer: Boosting is a sequential ensemble method: it trains weak learners one after another, each new learner focusing on the examples the previous ones got wrong (re-weighting misclassified points). Final prediction = weighted vote of all learners. Relation: boosting is an ensemble method — specifically an ensemble that builds learners sequentially and combines them, as opposed to bagging/random forests which build them in parallel and average.
CO5 · Q33 marks
Classifier A: 100% train, 70% test. Classifier B: 70% train, 75% test. Which is better? Justify.
Answer: B is better. A overfits (100% train vs 70% test — huge gap, it memorised training data, poor generalisation). B generalises (75% test ≥ 70% train — small gap, works on unseen data). The goal of a model is performance on new data, so test accuracy is what matters. B wins despite lower training accuracy.
CO5 · Q43 marks
What are ROC space and the ROC curve? Which points are perfect prediction, always-positive, and always-negative? Why?
Answer: ROC space plots classifiers by FPR (x-axis) vs TPR (y-axis). The ROC curve traces a classifier's TPR/FPR as its decision threshold is varied. Perfect prediction: (0,1) — zero false positives, all true positives. Always-positive: (1,1) — every point predicted positive, so all positives caught (TPR=1) but all negatives also wrong (FPR=1). Always-negative: (0,0) — nothing predicted positive, so TPR=0 and FPR=0. The diagonal (0,0)→(1,1) is random guessing.
CO5 · Q53 marks
Three classifiers with (FPR, TPR): A(0,1), B(1,1), C(1,0.5). Which is perfect? Justify.
Answer: A(0,1) is perfect — it sits at the ideal corner: FPR=0 (no false alarms) and TPR=1 (catches all positives). B(1,1) is always-positive (no discriminative power), C(1,0.5) is worse than random on the useful side (half the positives caught but every negative wrong). A dominates.

Model Question Paper — Part A (3 marks each, answer all)

10 questions
Part A · Q13 marks
Define supervised learning. Name special cases depending on whether inputs/outputs are categorical or continuous.
Answer: Supervised learning learns a mapping from inputs X to outputs Y from labelled training data (each example has the correct answer). Two special cases by output type: classification — output is categorical (e.g. spam/not-spam); regression — output is continuous (e.g. predict house price). (Inputs being categorical vs continuous describes the feature type, not the learning task.)
Part A · Q23 marks
Differentiate between Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP) estimation.
Answer: MLE chooses the parameter that maximises the likelihood of the observed data P(data | θ) — purely data-driven, no prior. MAP chooses the parameter that maximises the posterior P(θ | data) ∝ P(data | θ)·P(θ) — it adds a prior belief P(θ). MLE = MAP with a uniform prior. MAP is the Bayesian view (folds in prior knowledge); MLE is the frequentist view (let the data speak).
Part A · Q33 marks
What is overfitting and why is it a problem?
Answer: Overfitting is when a model learns the training data (including its noise and quirks) so well that it performs badly on new, unseen data. The gap between training accuracy and test accuracy is large. It is a problem because the whole point of ML is to generalise to new data; an overfit model has memorised instead of learned the underlying pattern, so it fails in practice.
Part A · Q43 marks
Specify the basic principle of the gradient descent algorithm.
Answer: Gradient descent minimises a loss/cost function J(θ) by iteratively moving the parameters down the slope: θ ← θ − η·∇J(θ), where η is the learning rate and ∇J is the gradient. It takes small steps opposite to the gradient (the direction of steepest increase), so each step reduces the cost. Repeat until the gradient is ~0 (a minimum). Learning rate too big → overshoot/diverge; too small → slow.
Part A · Q53 marks
Linear SVM binary classifier. A point is correctly classified and far from the decision boundary. If you remove it and re-train, does the boundary change? Justify.
Answer: No, it stays the same. The SVM's decision boundary depends only on the support vectors — points on (or inside) the margin. A point that is correctly classified and far from the boundary is not a support vector, so removing it changes neither the margin nor the solution. The boundary is identical.
Part A · Q63 marks
Mention the primary motivation for using the kernel trick.
Answer: To get the power of a very high (even infinite) dimensional feature space for non-linear classification without ever computing the mapping explicitly. The kernel computes the required dot products in feature space directly and cheaply, so training stays tractable while the model captures complex, non-linear boundaries.
Part A · Q73 marks
EM is for finding the MLE when some data is missing. Does it converge? To a local or global optimum?
Answer: Yes, the EM algorithm converges — each iteration is guaranteed not to decrease the (observed) likelihood. But it converges only to a local optimum (or a saddle point), not necessarily the global one. Where you start (initial parameters) matters; multiple restarts are often used to find a better local maximum.
Part A · Q83 marks
Illustrate the strength and weakness of k-means. (Same as CO4-Q2.)
Answer: Strength: simple, fast, scales well, easy to interpret via centroids. Weakness: must pre-set k; sensitive to initial centres and to outliers; assumes spherical, equal-variance, similar-sized clusters; every point forced into a cluster (no noise class). (See CO4-Q2 for the fuller version.)
Part A · Q93 marks
Classifier A: 100% train, 70% test. Classifier B: 70% train, 75% test. Which is better? (Same as CO5-Q3.)
Answer: B is better — A overfits (memorised training data, poor generalisation); B generalises (higher test accuracy, small train/test gap). Test performance on unseen data is what matters.
Part A · Q103 marks
How does the bias–variance trade-off affect machine learning algorithms?
Answer: Expected error = bias² + variance + noise. Bias = error from oversimplified assumptions (underfitting — too rigid). Variance = error from sensitivity to training noise (overfitting — too complex). Increasing model complexity lowers bias but raises variance, and vice-versa. The trade-off is finding the sweet spot (regularisation, more data, ensembles) that minimises total error.

Part B · Q11(a)7 marks
Discrete random variable with the given p.m.f. (0 ≤ θ ≤ 1). Observations: 3, 0, 2, 1, 3, 2, 1, 0, 2, 1. Find the MLE of θ.
Answer: The p.m.f. is given in the paper as a small table over x = 0,1,2,3 in terms of θ. Write the likelihood as the product of the 10 observed probabilities (counting how many times each x appears: x=0 twice, x=1 three times, x=2 three times, x=3 twice). Take the log, differentiate w.r.t. θ, set to 0. Because the exact table values weren't extractable as text, the method is: L(θ) = Π p(xᵢ;θ); ℓ(θ) = Σ count(x)·ln p(x;θ); solve dℓ/dθ = 0. With the concrete p.m.f. this gives a closed-form θ̂ (a rational number). Substitute the counts and solve — the answer is the MLE that maximises the observed frequencies.
Part B · Q11(b)7 marks
Three-class problem, y ∈ {0,1,2}, 3 binary attributes. How many parameters for Naive Bayes? (Same as CO2-Q2.)
Answer: Class prior P(y): 3 classes, sums to 1 → 2 free params. Conditionals P(Xⱼ|y): 3 attributes × 3 classes = 9, each sums to 1 → 9 − 3 = 6. Total = 8 parameters.
Part B · Q13(a)7 marks
Linear regression hθ(x)=θ₀+θ₁x, cost J=½m Σ(hθ(x⁽ⁱ⁾)−y⁽ⁱ⁾)². Given training examples, find (1) hθ(2) if θ₀=0, θ₁=1.5; (2) J(0,1); (3) what if J=0?
Answer: (1) hθ(2) = 0 + 1.5·2 = 3. (2) J(0,1) = ½m Σ((0+1·x⁽ⁱ⁾) − y⁽ⁱ⁾)² — substitute the given (x,y) pairs and sum. (3) If J(θ₀,θ₁)=0, the line passes exactly through every training point with zero error — a perfect fit on the training data (which on real data would usually mean overfitting).
Part B · Q13(b)3+4 marks
750 students, 150 staff, 100 professors. Blond hair: 50 staff, 250 students, all professors. Compute information gain of "hair colour = blond". Explain regularization (Ridge vs Lasso).
Answer (info gain): Total N = 1000. Prior entropy H = −Σ pᵢ log₂ pᵢ for {prof 0.10, staff 0.15, stud 0.75}. For the test "blond = true": 100 prof + 50 staff + 250 stud = 400, P(blond)=0.4; within it {0.25, 0.125, 0.625}. For "blond = false": 600, {0, 0.10·150/600?…} compute entropy of each child, weight by 0.4/0.6, subtract from H → information gain.
Regularisation: adds a penalty to the cost for large weights to reduce overfitting. Ridge (L2) penalises Σwᵢ² — shrinks weights toward 0 but keeps all features. Lasso (L1) penalises Σ|wᵢ| — can shrink weights exactly to 0, giving feature selection. Ridge keeps correlated features; Lasso picks one.
Part B · Q14(a)7 marks
Dataset to predict car ownership; features: education (primary/secondary/university), residence (city/country), gender (female/male). Use ID3 and find the best root attribute.
Answer: ID3 picks the root attribute with the highest information gain (or lowest entropy) on the labelled examples. Compute the entropy of "owns car?" for the full set, then for each candidate attribute compute the weighted average child entropy after splitting, and gain = parent entropy − that average. The attribute with the largest gain becomes the root. (The concrete instance table wasn't extractable as text — apply the formula to the given rows: split on education / residence / gender, compute each gain, pick the max. Typically "education" or "residence" dominates for this kind of social dataset.)

WA · Q44 marks
Compute the ML estimate for the parameter p in the binomial distribution whose probability function is f(x) = C(n,x) pˣ (1−p)^(n−x), x = 0,1,2…n.
Answer: For x successes in n trials, likelihood L(p) = C(n,x) pˣ (1−p)^(n−x). Drop the constant C(n,x): ℓ(p) = x ln p + (n−x) ln(1−p). dℓ/dp = x/p − (n−x)/(1−p) = 0 → x(1−p) = (n−x)p → x = np → p̂ = x/n (the observed proportion of successes).

WA · Q64 marks
Define Bayes' theorem and discuss its terminologies.
Answer: P(A|B) = P(B|A)·P(A) / P(B).
Terminologies: P(A) = prior probability of A (before seeing B); P(B|A) = likelihood (probability of evidence B given A); P(A|B) = posterior (updated probability of A after seeing B); P(B) = evidence / marginal, a normalising constant = Σ_A P(B|A)P(A). Used to update belief from prior to posterior using observed data.

WA · Q8—
MLE vs MAP.
Answer: MLE maximises P(D|θ) — picks the parameter that best explains the data, ignoring prior belief. MAP maximises P(θ|D) ∝ P(D|θ)·P(θ) — also includes a prior P(θ), acting as regularization. With a uniform prior, MAP = MLE. As data grows, MAP → MLE (prior stops mattering). MLE can overfit small data; MAP is more stable when data is scarce or domain knowledge exists.
